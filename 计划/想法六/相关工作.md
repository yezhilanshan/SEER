# 相关工作：SNN 用于连续动作识别

> 2026-10-26 整理。合并自两次独立检索：重复工作已去重，冲突信息逐条标注。
> 检索覆盖视频、事件相机、毫米波雷达、WiFi、IMU 五个模态，**并非穷尽检索**。DVS-Gesture-Chain 与 Wi-Spike 读了全文，其余主要看摘要。

## 0. 结论先行

**有，但很少。** 找到的工作基本都是"把整个网络换成脉冲网络来省电"，没有找到"把 LIF 当事件门去切连续信号、再接语言模型"的工作。

截至 2026 年 10 月，SNN 已被用于：

- 在线视频动作识别与预测（KDSNN）
- 未裁剪视频的动作时间定位（SpikeTAD）
- 连续手势链的顺序识别（DVS-Gesture-Chain）
- 毫米波雷达手势分类（多篇）

但有一个关键区别：

> 现有研究证明了 SNN 能识别动作、能用于连续视频中的动作检测；但直接利用 SNN 的神经元状态实现毫米波连续动作的语义边界判断，仍然缺少成熟的代表性工作。

**三个检索缺口**：

1. 把 SNN / LIF 当作连续传感器流的事件分割门；
2. 用 SNN 神经元状态做毫米波连续动作的语义边界判断；
3. SNN + LLM 生成连续行为描述。

## 1. 先厘清任务类型

| 缩写 | 任务 | 要回答的问题 |
|---|---|---|
| OAD | 在线动作检测 | 此刻正在发生什么动作？ |
| TAD | 时间动作检测 | 每个动作发生在什么起止时间？ |
| Online TAS | 在线时序动作分割 | 连续输入下，实时判断动作序列及切换边界 |

你的目标最接近 **Online TAS**，且比它多两步：事件门控 + 语言描述。
KDSNN 主要研究 OAD，SpikeTAD 主要研究 TAD。

### 2.1 KDSNN：把 SNN 用于在线视频动作理解

IEEE Transactions on Industrial Informatics，2026
论文：[Knowledge Distillation-Based Spiking Neural Network for Online Video Action Understanding](https://doi.org/10.1109/TII.2025.3641291)

这是与"流式"目标最接近的一篇。它面对持续到来的视频，而不是已裁剪好的动作片段。

核心结构：

1. **Hierarchical Spike CNN**：提取空间与局部运动特征。
2. **Spike Transformer**：建模动作的时序依赖。
3. **知识蒸馏**：先用 ANN 学到较好的动作语义，再迁移到 SNN。
4. **跨表示对齐**：用最优传输与 Wasserstein 距离，缩小 ANN 连续特征与 SNN 离散特征之间的差异。

实验用 THUMOS14 与 EPIC-Kitchens-100，报告能耗分别为 ANN 基线 MAT 的 27.1% 和 10.0%。

**可借鉴**：蒸馏思想可以改成——训练期用 RGB-D 骨架网络当教师，推理期用毫米波雷达网络当学生，SNN 负责时序证据的累积与更新。

**限制**：核心仍是在线动作检测与预测，没有证明能解决相邻动作的精确语义边界。

### 2.2 SpikeTAD：SNN 可以预测动作起止时间

Pattern Recognition，2026
论文：[SpikeTAD: Spiking Neural Networks for End-to-End Temporal Action Detection](https://arxiv.org/abs/2606.12033)
代码：[MCG-NJU/SpikeTAD](https://github.com/MCG-NJU/SpikeTAD)

目标很明确：给定一段未裁剪视频，输出

\[ \{(t_i^{start}, t_i^{end}, c_i)\}_{i=1}^{N} \]

方法不是设计新的动作切换机制，而是：

1. 先训练常规 ANN 动作检测模型；
2. 用 ANN-to-SNN Conversion 把网络转成脉冲网络；
3. 骨干网络中使用多阈值神经元（MTN）与期望补偿模块（ECM）；
4. 动作检测头中使用 IF 神经元。

| 数据集 | 平均 mAP |
|---|---|
| THUMOS14 | 67.2% |
| ActivityNet-1.3 | 37.42% |

**两个与本课题相关的限制**：

- 主要是离线时间动作检测，不能直接当作因果流式分割网络。
- SNN 的内部计算时间步不等于视频帧的真实时间步。论文专门讨论了 Semantic Time 与 Computational Time 的区别。

**结论**：SpikeTAD 证明的是 SNN 能承担动作定位任务，而不是"LIF 放电天然就能表示动作边界"。

### 2.3 DVS-Gesture-Chain：最值得关注的时序思想

Neurocomputing（arXiv 2022）
论文：[Spiking Neural Networks for Event-Based Action Recognition: A New Task to Understand Their Advantage](https://arxiv.org/abs/2209.14915)
代码与数据构建：[DVS-Gesture-Chain](https://github.com/vicentealex/dvs-gesture-chain)

**切入点**：传统 DVS-Gesture 只要求识别单个手势，这不一定需要模型理解时间关系——单个动作内部已有足够特征用于分类。于是作者把多个手势按顺序组成"动作链"，要求模型理解出现顺序。例如 A→B 与 B→A 包含相同动作，但结果不同。

作者研究了：神经元衰减率如何影响时序理解；复位机制如何影响历史信息保留；循环 SNN 如何利用状态记忆识别顺序。结论是：SNN 的时间动态确实能支持时序依赖建模，而不只是降低能耗。

**但最终仍是对动作链分类，不是为链中每个动作输出起止时间。** 这恰好指出研究缺口：

> SNN 可以理解动作顺序，但如何让它判断"上一个动作何时结束、新动作何时开始"，仍需额外设计。

#### 复位方式的消融结果（81 类手势链）

| 漏电 | 复位方式 | 准确率 | 备注 |
|---|---|---|---|
| 无（IF） | 发火后减阈值 | 48.27% | **最差**，即当前方案里的 CIF 基线 |
| 无（IF） | 发火后清零 | 92.59% | 明显更好 |
| 有（LIF） | 发火后减阈值 | 86% | 明显更好 |
| 有（LIF） | 发火后清零 | 低于 92.59% | 原文具体值未记；**叠加并不更好** |

原因：残余电压会拖慢后续发火，造成"重复错误"。

**注意**：这是事件相机上的整串分类结果，不能直接搬到雷达分割。但值得据此把消融改成 **2×2（漏电有无 × 复位减阈/清零）**，并在其上再叠加"回溯定边界"模块。四格都要跑，不能假设"漏电 + 清零"叠加更优。原先只排了"软复位 vs 硬复位"一项，不够。

#### 造数据方式（可直接借用）

把单动作样本串成链，并随机每段时长，避免模型靠"第几秒换动作"作弊。

自采数据完成前，可用 PARrad 已有的动作片段合成类似的合成长序列，先验证 S1、S2。**但拼接处是人为突变，比真实动作转换更容易检测**——只能用于预训练与消融，不进主结果。

### 2.4 EEvAct 与 TrueNorth

- EEvAct（2025）：双流 SNN 持续处理事件相机数据，在动作尚未结束时提前识别。
- TrueNorth（CVPR 2017）：在 TrueNorth 芯片上持续处理事件流，实时事件相机流上约 105 ms 识别手势起始。

两者都是单个动作/起始检测，不处理连续多动作。

### 2.5 Wi-Spike 与 PAS-Net（其他模态）

- **Wi-Spike（2026，WiFi）**：把 2–3 个单动作样本拼成"多动作"样本，每个样本整体给一个标签，不是逐帧预测。即"拼接样本整体分类，没有边界和描述"。
- **PAS-Net（2026，IMU）**：面向连续 IMU 流的亚秒级流式早退出，本质仍是窗口分类。

### 3.1 Frequency Matching：对本课题最有价值

2026，预印本。代码：[yudi-mars/Soul](https://github.com/yudi-mars/Soul)

核心观点：LIF 神经元不仅有时间记忆，还有**频率选择特性**。

\[ u_t = \beta u_{t-1} + I_t \]

其中 \(I_t\) 为当前输入，\(u_t\) 为膜电位，\(\beta\) 为历史状态保留程度。作者分析膜电位衰减与毫米波信号频率结构的关系，通过匹配输入中具有判别力的频率成分来设定衰减参数。

在四个毫米波数据集上：平均识别准确率相对 ANN 基线提高约 6.22%，理论能耗降低约 3.64 倍。

**启发**：连续动作存在不同时间尺度——

- 挥手：较快的局部运动变化；
- 行走 → 停止：较缓慢的整体状态变化；
- 持续行走：存在周期性变化，但不产生新动作。

单一衰减参数难以兼顾。可考虑不同时间常数的神经元群：

\[ u_t^{(k)} = \beta_k u_{t-1}^{(k)} + W_k h_t \]

让不同分支处理快速、缓慢与周期性运动。**但仍需额外判断这些变化是否具有语义意义。**

### 3.2 Hybrid Radar SNN：容易落地的结构

论文：[Spatiotemporal Radar Gesture Recognition with Hybrid Spiking Neural Networks](https://arxiv.org/abs/2509.23303)
代码：[rmazzier/Radar-Gesture-Recognition-with-Hybrid-SNNs](https://github.com/rmazzier/Radar-Gesture-Recognition-with-Hybrid-SNNs)

结构：CNN 处理雷达空间特征，LIF 处理运动的时间变化。报告中相比基线训练参数减少约 88%，分类准确率下降不足 1%。

**价值**：支持一种务实思路——不必把整个 Radar Encoder 都换成 SNN，只在时间建模部分引入 SNN。

## 4. 骨架动作识别 + SNN

已完成毫米波与 3D 骨架的时间对齐，这部分也值得关注。

| 工作 | 方法 | 可借鉴之处 |
|---|---|---|
| [MK-SGN](https://arxiv.org/abs/2404.10210) | 脉冲图卷积，融合关节、骨骼、运动特征，并采用知识蒸馏 | 骨架教师网络 + 雷达学生网络 |
| [Signal-SGN](https://arxiv.org/abs/2408.01701) | 脉冲图卷积 + 时域/频域特征建模 | 多时间尺度的动作动态 |
| [S3T-Former](https://arxiv.org/abs/2603.18062) | 骨架运动差分 + 脉冲拓扑路由 + 状态空间记忆 | 运动变化检测与长期状态维护 |

以上研究主要评价**完整动作片段的分类**，而非连续动作分割。

**S3T-Former 的三个设计尤其值得读**：

1. **运动差分编码**：从关节位置及其变化构造稀疏动态表征。
2. **脉冲拓扑路由**：根据当前活跃关节选择性传播信息。
3. **状态空间记忆**：维护比普通 LIF 更长时间的历史信息。

作者明确指出：普通 LIF 的指数衰减可能导致长期记忆不足，因此额外设计状态空间记忆模块。

即便它使用因果状态更新，也不能直接视为已经完成在线连续动作分割。

## 5. 为什么 SNN 适合连续动作，却不能直接给出边界

这是最关键的研究问题。

### 5.1 能检测变化，但变化不等于动作切换

设连续输入为：站立 → 行走 → 停止 → 坐下。

持续行走时，雷达信号会随迈步周期反复变化。若用

\[ s_t = H(u_t - \theta) \]

并把每次放电解释为动作切换，那么左腿前迈、右腿前迈、摆臂幅度变化都可能放电——一个完整的行走会被切成多个"事件"。

反之，人从行走到静止的缓慢过渡中，单个时间步的变化可能很小，仅靠局部变化阈值又会漏检。

**因此：神经元放电表示某种内部激活达到阈值，并不天然对应动作语义边界。**

### 5.2 单个 LIF 神经元不知道自己属于哪个动作

"行走中的一次迈步"与"行走结束前的最后一步"，局部运动特征可能十分相似，语义却不同。人能区分，靠的是综合：

- 当前运动模式；
- 已持续的历史行为；
- 运动变化是否稳定；
- 后续是否进入新的动作状态。

SNN 有时间状态积累能力，但需要学习这些语义判别依据，不会仅凭膜电位累积自动获得动作边界的定义。

## 6. 创新点定位

**"SNN 雷达"已经有很多，不能当卖点。** 真正的点是：

> 用 LIF 动力学做事件门，把连续流变成事件，并按事件唤醒 LLM。

相关工作里应把 **SpikeTAD、DVS-Gesture-Chain、Wi-Spike** 列为直接对比对象。

| 方向 | 目前进展 | 判断 |
|---|---|---|
| SNN + 雷达单动作分类 | 已有多篇工作 | 创新空间有限 |
| SNN + 视频动作时间定位 | SpikeTAD 已实现 | 不能以"首次结合"为创新 |
| SNN + 在线动作检测 | KDSNN 已实现 | 已有直接先例 |
| SNN + 动作链顺序理解 | DVS-Gesture-Chain 已探索 | 值得扩展到事件级预测 |
| SNN + 毫米波连续动作语义边界 | 本次检索未找到代表性工作 | 值得研究 |
| SNN + 雷达事件状态 + 自然语言描述 | 本次检索未找到完整方案 | 有进一步探索价值 |

**核心判断**：真正值得探索的不是"用 SNN 做连续动作识别"，而是

> 利用 SNN 的多时间尺度状态积累形成运动变化证据，再通过语义一致性判断决定何时切换动作事件。

这才与简单的 SNN 分类器、低功耗检测器有实质区别。

## 7. 对方案的影响

### 7.1 最小验证结构

先不绑定方案书 v2.6 / v1.0，独立验证下面这条链路：

```
毫米波雷达连续输入
  → RD / Point Cloud
  → Radar Encoder（提取连续运动表征 h_t）
  → 双分支：
       ├─ 语义状态分支：当前动作是什么？当前状态是否稳定？
       └─ 多时间尺度 SNN：运动证据是否发生持续变化？
  → 语义切换判别模块（融合运动证据与语义稳定性）
  → 连续事件输出（动作类别、起止时间、事件表示）
```

两条分支的分工是重点：

- **SNN 分支**：提供运动状态变化的证据；
- **语义分支**：判断变化是否足以构成新的动作。

训练时可用已采集的骨架数据提供辅助监督（关节速度、局部运动变化、姿态状态），但**边界最终仍应使用真实动作段标注训练**。

### 7.2 消融设计

**(a) 结构消融（四组）**

| 实验 | 目的 |
|---|---|
| ANN + 普通边界头 | 基础性能 |
| ANN + 连续值泄漏积分器 | 判断时间积分本身是否有效 |
| ANN + LIF 边界分支 | 判断脉冲机制是否额外有效 |
| ANN + 多尺度 LIF + 语义判别 | 验证运动证据与语义联合判断 |

这组消融回答一个关键审稿问题：**性能提升来自 SNN 的脉冲机制，还是仅仅来自增加了时间记忆？**

**(b) 神经元复位消融（2×2）**

漏电（有/无）× 复位（发火后减阈/清零），共四格，再叠加"回溯定边界"作为增量项。依据见 2.3：CIF（无漏电 + 减阈）是最差配置（48.27%），且"漏电 + 清零"并不优于"仅清零"，所以四格必须全跑。

### 7.3 合成数据预训练

用 PARrad 已有动作片段合成随机时长的长序列，先验证 S1、S2。仅用于预训练与消融，主结果仍用真实连续数据（原因见 2.3）。
