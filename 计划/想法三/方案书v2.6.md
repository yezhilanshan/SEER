# 一、摘要与研究定位

## 1.1 研究目标

输入单人室内连续毫米波数据流（RD Map、Point Cloud、时间戳），在**不依赖推理时摄像头、人体姿态 GT、人工边界或固定动作类别表**的条件下，在线形成具有起止时间的事件表示，保留事件顺序与关键运动细节，并在事件定稿或用户查询时生成自然语言描述。

最终输出：

$$
\mathcal{E}=\{(t_i^s,t_i^e,E_i,z_i,c_i,y_i)\}_{i=1}^{N},
$$

其中 $E_i$ 是语言模型维度的事件 Token，$z_i$ 是检索语义向量，$c_i$ 为置信度，$y_i$ 为描述文本。实时阶段可以先输出 provisional 时间线，确认后异步修正时间与状态。

## 1.2 根本研究问题

v2.5 主要研究“发生了变化吗、变化是否形成新事件、边界在哪里”，依赖显式的候选检测和验证流程。v2.6 重新研究：

> **事件是否可以作为连续运动预测模型的自适应内部状态，在学习预测、解释与压缩行为时自主决定何时继续和何时重置？**

新方案不把边界作为唯一的前置检测目标，而是令事件重置决策改变后续状态及预测损失；真实边界只在训练和评估时提供语义锚定。

必须保留的学术限定：**运动动力学的最佳分段不一定等同于人类动作语义分段**。例如快走转慢走可能需要不同动力学，而重复两次相同动作可能无需切换运动模型却需要形成两个语义事件。因此，预测学习不能完全取代语义/实例监督。

## 1.3 三条技术主张（待验证）

1. **Event State as Predictive State**：事件 Token 同时负责运动预测、当前语义和长期记忆，而不是单纯作为边界决策后的表示。
2. **Reset as Endogenous Decision**：每次语义更新直接推断继续/重置；Reset 改变事件状态，后续预测损失反向优化 Reset Policy；主路径无需独立 Proposal→Verify。
3. **Semantic-Constrained Predictive Segmentation**：通过少量真实动作实例边界、语义属性和事件压缩成本限制动力学分段退化，使事件既有预测价值也有语言价值。

**不能宣称的内容：** 无监督开放世界事件发现、严格贝叶斯最优、可证明实时、零样本泛化、系统性能优于 v2.5，除非对应实验成立。

# 三、时间与输入契约

- 雷达帧率：20 fps（每帧 50 ms）；每 4 帧执行一次语义更新，即 5 Hz，$\Delta=0.2$ s。
- Radar Encoder：RD 分支（2D CNN + stateful causal TCN）；Point 分支（PointNet + stateful causal TCN）；融合后每 update 产生四个 Token：

$$
F_t=[R_t^1,R_t^2,P_t^1,P_t^2]\in\mathbb R^{4\times256}.
$$

- 模型允许额外从 $F_t$ 计算紧凑运动表征 $m_t=f_m(F_t)\in\mathbb R^{256}$，但预测监督的 target 必须来自**冻结或停止梯度的目标编码器**，防止模型通过改动 target 使预测任务塌缩。
- Radar Encoder 输出的 update 时间必须对应明确原始帧区间；所有边界精修、文本标签和缓存回放均使用同一绝对时间轴。
- Presence/Idle 控制器独立：无人在场不是“新的动作事件”，缺失数据时不根据异常 NLL 反复重置。

主要张量：

| 张量 | 建议维度 | 说明 |
|---|---|---|
| $F_t$ | 4×256 | RD/Point 的融合 Radar Tokens |
| $m_t$ | 256 | 被预测的 motion latent |
| $E_t$ | 8×3584 | Streaming Event Tokens，默认 K=8 |
| $z_t$ | 128 | Semantic Projection |
| $e_t$ | 任务相关 M 维 | Evidence Projection |
| $q_t$ | scalar | 当前 update 的新事件 Reset 概率 |
| $a_t$ | scalar | 当前事件生存时间，秒 |

这些维度继承 v2.5 的既定接口或为 v2.6 建议值；非新实验结果。

# 五、核心模块 A：Predictive Event State Model

## 5.1 定义两个状态演化函数

令 $U_\theta$ 为沿用 v2.5 的 Event Former（固定 Event Prompt、LLM 前四层、512-d 瓶颈 Cross-Attention、Event Update Gate）。在时刻 $t$ 已看到 $F_t$ 后：

$$
\widetilde E_t^K=U_\theta(E_{t-1},F_t),\qquad
\widetilde E_t^R=U_\theta(P_{base},F_t).
$$

Keep 表示旧事件继续；Reset 表示从同一个可学习的基础 Event Prompt 开始新事件。无事件类别 ID；动作重复也必须有机会 Reset。

### Reset 时间的严格含义

如果 $r_t=1$，则新事件第一批观测是当前 update $F_t$，边界约定为该 update 覆盖帧区间的**起点**，不是当前 update 结束时间。由此在线原始定位精度初期受 0.2 s update 网格限制；更精细时间由异步边界精修补偿。

## 5.2 预测的先后顺序（防止未来泄漏）

在观察 $F_t$ 前，根据 $(E_{t-1},m_{t-1})$ 输出旧事件运动预测：

$$
p_K(m_t)=p_\psi(m_t\mid E_{t-1},m_{t-1}).
$$

同时由历史上下文 $h_{t-1}$ 估计“若在 t 新生一个事件”时的第一步观测分布：

$$
p_R(m_t)=p_\omega(m_t\mid h_{t-1},\text{birth}).
$$

然后收到 $F_t$，提取 $m_t$，**用相同真实观测评分两个预测分布**。注意 $p_R$ 必须是基于过去的 *birth prior*，不能先使用当前 $F_t$ 重置再重构当前 $F_t$ 来作弊；也不能让旧事件与新生模型看到不等量的未来信息。

初始化阶段：使用 oracle 分段中的事件内帧训练 $p_K$，使用事件开始帧训练 $p_R$，在独立拟合数据上标定似然尺度。Birth prior 可以根据近期雷达上下文生成，但不能输入 GT 边界或未来帧。模型不得通过无限增大方差规避错误（固定方差范围、校准 NLL、检查 sharpness）。

## 5.3 Reset Policy

定义生存/切换先验 $\pi_t=h_\phi(a_t,h_{t-1})$，其中 $a_t$ 是物理秒数，先验输出需要被限制在 $[\epsilon,1-\epsilon]$，**不强制累计随持续时间单调增加**。

可以首先使用概率比较的 logit：

$$
\eta_t=\operatorname{logit}(\pi_t)+
\log p_R(m_t)-\log p_K(m_t).
$$

$$
\boxed{q_t=\sigma(\eta_t/T_q)}.
$$

若实验证明简单似然比不足，可增加一个极小的 residual MLP 读取已校准的预测残差/雷达可靠度，并通过配对消融验证。$q_t$ 只表示当前 update 开启新事件的偏好；未经概率校准不能直接宣称是正确的贝叶斯后验。

重要限制：**“新生分布比旧预测分布大”不自动等价于语义变化**。语义锚定必须由 Stage 2–3 的真实事件监督和预测后果学习实现。

## 5.4 Event State 真正由决策改变

$$
r_t\in\{0,1\},\qquad
E_t=(1-r_t)\widetilde E_t^K+r_t\widetilde E_t^R.
$$

式中前向的 $r_t$ 必须是硬选择，所以不会在真实推理时将两个不同事件的语义混为一体。新 $E_t$ 参与后续时刻的预测、语言读取和历史状态形成。**若切换决策没有影响状态的未来运动损失，则它仍是边界分类器，不构成本方案的核心机制。**

# 六、核心模块 B：Predictive Dynamics Head

## 6.1 结构建议

Event Tokens $E_t$ → 语义无关的 query pooling（3584→256）→ 与 $m_t$ 及物理可靠性量拼接 → 两层小 MLP → 输出未来 motion latent 的高斯均值和对角方差。

$$
p_\psi(m_{t+h}\mid E_t,m_t)=\mathcal N(\mu_{t,h},\operatorname{diag}(\sigma_{t,h}^2)).
$$

初始 $h=1$（0.2 s），升级 $h\in\{1,3,5\}$（0.2/0.6/1.0 s）。避免直接预测完整 RD Map/点云，因为静态背景与随机反射容易主导损失。可附加物理属性预测（运动能量、径向速度、位移）以验证 latent 保留运动信息，但物理属性不应从 GT Skeleton 在推理阶段注入。

## 6.2 预测损失

$$
\ell_{t,h}=-\log p_\psi(\operatorname{sg}(m_{t+h}^{target})\mid E_t,m_t),\qquad
\mathcal L_{pred}=\operatorname{Avg}_{recording}\operatorname{WeightedAvg}_{h}
\operatorname{Avg}_{t\in\mathcal V_h}(\ell_{t,h}/D).
$$

$\mathcal V$ 仅包含确实有有效未来观测和人存在的合法项；长 horizon 不跨样本录制断点。每条轨迹按合法时间步数归一，防止长样本压倒短样本。

这里 $D$ 为预测目标维度，联合 NLL 与训练用的每维平均 NLL 分别记录；精确展开、horizon 权重和空集合处理见第十八章 18.2。Reset 似然比较不直接套用训练平均值，证据尺度另按 18.5 标定。

**防止退化：** motion target 来自冻结的 Radar Encoder / EMA teacher 并停止梯度；预测器与相同历史输入的纯 TCN/GRU 基线比较；检查 variance clipping、NLL、MSE、校准；检查人为空、动作转换及长稳态分别表现。

## 6.3 准确预测是否必然导向动作事件？

不必然。正常波动可以预测不准，突然速度变化可能动力学显著但语义上仍同一动作，两个重复相同动作可能预测同样良好。训练目标必须同时包括真实事件层面的约束。本章只确保状态具备预测能力，不能单独证明语义事件发现。

# 七、核心模块 C：事件 Reset 的可微训练

## 7.1 Oracle 初始化，Closed-loop 主训练

训练初期直接使用 GT 分段切换更新事件状态（teacher forcing）；形成具备合理内部运动模型的 Keep/Reset 状态后，逐渐增加模型自主决策的比例，最终完全 Closed-loop 推理。Oracle 作为 rehearsal regularization，不与 Closed-loop 样本粗暴 concat 再平衡。

## 7.2 硬前向、软反向

设 $a_t^{reset}=\eta_t/T_q$，$q_t=\sigma(a_t^{reset})$；$a_t^{reset}$ 是 Reset logit，与事件生存时间 $a_t$ 区分。采用 Straight-Through Gumbel-Sigmoid 作为第一版近似：

$$
\widetilde r_t=\sigma((a_t^{reset}+g_t)/\tau),\qquad
r_t^{hard}=\mathbb1[\widetilde r_t>0.5].
$$

实现上用 $r_t=r_t^{hard}-\operatorname{sg}(\widetilde r_t)+\widetilde r_t$；前向硬选择、反向近似通过 $\widetilde r_t$。此梯度**有偏**，必须和非可微的监督边界分类器、软混合训练及小规模 K-best 假设跟踪作消融。不能宣称其自动找到全局最优事件切分。

二元松弛的 $g_t=\log u_t-\log(1-u_t)$，$u_t\sim\mathrm{Uniform}(0,1)$，为 Logistic 噪声（等价于两项独立 Gumbel 的差），不是单个标准 Gumbel。概率校准温度 $T_q$ 与松弛温度 $\tau$ 分开记录；具体梯度路径见 18.6。

在主阶段以短时截断反向传播（TBPTT）运行闭环轨迹。先冻结 Backbone/Prediction Head 只优化 Reset Policy，再小幅解冻 Event Update Gate 和预测头；保留语义投影和语言 Reader 被保护面。

## 7.3 延迟决策和假设维持

“每步都估计 Reset 概率”不表示“每步立即永久提交”。可使用三个逻辑动作：Continue、Defer、Seal/Reset。$q_t$ 接近不确定区间时，保留 bounded ring buffer 与至多两个短期分支，选择后重新对齐状态。此操作是**状态推断不确定性管理**，而非 v2.5 那种先有 Physical Proposal 才启动的 Fork 机制。

MVP 允许硬阈值加固定最大确认延迟；完整版使用小型 K-best run-length 假设（如 K=2，具体预算需实测）。原则：单次 5 Hz 更新不得无界分叉、无界重算或无限期 Defer。

# 八、监督如何构造：动作边界不是最终唯一目标

## 8.1 可用监督的角色

| 监督 | 从哪里来 | 训练哪部分 | 推理是否依赖 |
|---|---|---|---|
| 未来 Radar motion latent | 同一录制流未来时刻，冻结目标编码器输出 | Predictor 与重置后果 | 否 |
| 真实事件起止时间 | 连续序列人工标注、视频辅助标注 | 初始 Reset Policy、事件匹配 | 否 |
| 同类动作不同实例 ID | 连续序列真实实例索引 | 重复事件不被合并 | 否 |
| 骨架/关节速度 | 同步姿态（若有） | Stage 0 Pose 与 physical evidence | 否 |
| 事件级文字、动作属性 | 人工描述/审校文本 | Event Semantic/Caption | 否 |
| 长时事件问答/摘要 | 事件时间线与人工核查描述 | Compressor/LLM | 否 |

如果公开数据只有预裁剪单动作样本、没有真实连续边界，最多支撑 Radar Encoder 或事件预测的局部预训练，**不能声称已训练真实连续事件形成**。

## 8.2 事件级边界约束，避免逐帧 BCE 的弊端

在每条 GT 边界 $b_j$ 周围构建容差区间 $I_j=[b_j-\delta,b_j+\delta]$，令 $q_t$ 为该处 Reset 概率，定义至少有一次 Reset 的软覆盖：

$$
\mathcal L_{cover}=-\frac1J\sum_{j=1}^J\log\left(1-\prod_{t\in I_j}(1-q_t)+\epsilon\right).
$$

为防止一个边界窗口重复重置：

$$
\mathcal L_{dup}=\frac1J\sum_j\left(\sum_{t\in I_j}q_t-1\right)^2,
$$

以及非边界区间的期望误报成本：

$$
\mathcal L_{off}=\frac{1}{|\mathcal O|}\sum_{t\in\mathcal O}q_t.
$$

**注意：** $\mathcal L_{dup}$ 约束的是概率总量，不等于保证每条硬推理轨迹恰好出现一次 Reset；最终必须采用**事件级一对一匹配**评估，并可在训练后期使用匹配损失微调。重叠 GT 容差窗口要先合并/处理，不能将一个 reset 配给两条真边界。边界标签有效性由标注审计确认。

$$
\mathcal L_{weak-bnd}=\lambda_{cov}\mathcal L_{cover}+\lambda_{dup}\mathcal L_{dup}+\lambda_{off}\mathcal L_{off}.
$$

在没有 GT 的序列，此项跳过，仅用于预测自监督；不能将无标签片段粗暴全部标负例。

## 8.3 实例语义约束

给每条有标注的 GT 事件 $e_j$ 产生冻结 Commit Teacher 的事件语义 $z_j^{teach}$。对流式生成、与该实例时间匹配的事件 $z_j^{stream}$，使用：

$$
\mathcal L_{sem-distill}=\frac1{J_{matched}}\sum_j[1-\cos(z_j^{stream},\operatorname{sg}(z_j^{teach}))].
$$

未匹配事件不强行配对文本；应计入漏检/误检。为避免同类动作连续重复被合并，除文本类别外还必须保留 **GT 实例边界 + duration + order** 监督。同类实例区分不等于只靠对比类别 embedding。

## 8.4 事件复杂度与 MDL

最简事件数量成本（按真实时间而非 batch 数计）：

$$
\mathcal L_{count}=\operatorname{Avg}_{s}
\frac{\sum_t\chi_{s,t}q_{s,t}}{\sum_t\chi_{s,t}\Delta_{s,t}}
\quad(\text{expected resets/sec}).
$$

其中 $s$ 是真实 recording，$\chi$ 标记合法 Reset 决策位置，排除外部初始化、确认无人及无效观测，$\Delta$ 是其有效覆盖秒数；空 recording 跳过。全部位置合法且固定更新周期时退化为 $\sum q/(T\Delta)$。此项是随机 Reset 数量的代理，不等于阈值与 DEFER 后的实际 final-event rate。

可选更完整的 rate–distortion 目标：

$$
\mathcal L_{MDL}=\mathcal D(\text{motion or semantic reconstruction})+\beta\,\mathcal R(\text{stored event codes}).
$$

**不得把固定长度 Event Tokens 的数量直接称为真实码长或信息熵。** 如果没有学习压缩编码概率模型，只能称 Token Budget Proxy。MVP 只用 $\mathcal L_{count}$；实际 MDL 分支必须经过独立重构/信息保留实验后才纳入核心 claim。

# 九、六阶段训练计划（Stage 0–5）

## Stage 0：Physical Pipeline & Frozen Baseline Audit

**目标：** 准备可复现输入、监督与旧权重，不新增训练目标。

- 检查 20 fps→5 Hz 更新对齐；RD/Point 时钟和帧合法性；GT boundary 单位/起止定义；Pose 与 Radar 同步；缺失帧/场景切换。
- 复用 v2.5 Radar Encoder 和姿态预训练产物；若必须预训练，仍采用 $\mathcal L_{pose}=\mathcal L_{MPJPE}+\lambda_v\mathcal L_{velocity}$，并在推理时删除 Pose Head。
- 运行 0-step 冻结层 probe、相同 checkpoint 的 v2.5 边界/检索/QA 基线；对比已知 TCN temporal_gate 注入问题，**先审计不直接强改 gate=1**。
- 以连续录制 Session 为单位切分数据，subject/environment 隔离，避免由重叠窗口造成泄漏。

**冻结：** 全部已训练模型。 **监督：** 既有时间/姿态标签只用于审计。 **验收：** 数据量纲、索引、特征 SHA、受试者分割均可追溯；没有“拼接样本假冒真实连续”的训练数据。

## Stage 1：Predictive Event Representation Pretraining

**目标：** 验证 Event State 是否提供超出普通运动短历史的预测价值。

**Step A：** 冻结 Encoder、Event Former、Semantic Reader 与运动目标分支，训练输入侧 Motion Projection（若需要）+ Dynamics Head；oracle 连续真事件分段可用于重置 Event State，但预测监督只取真实未来 Radar latent。目标侧投影不得与可训练输入侧投影混为一体，默认 $\mathcal L_{1A}=\mathcal L_{pred}$，详见 18.4。

**Step B（A 达到预注册门槛时）：** 只解冻 Event Update Gate/Cross-Attention/少量 LoRA，增加冻结旧语义表示保持损失：

$$
\mathcal L_{1B}=\mathcal L_{pred}+\lambda_{pres}\mathcal L_{state-preserve}.
$$

**对照：** Persistence（复制上一帧）、同规模 GRU/TCN、event-free predictor、event-conditioned predictor；相同预测 horizon、target 和训练预算。

保持损失比较新旧模型的相同可见输入与相同 Reset 路径，不能强制不同事件划分产生的状态逐帧相等；公式、教师冻结与计算粒度见 18.4。

**验收：** 冻结未见受试者/场景的预测 NLL/MSE 有匹配收益；不会靠预测方差膨胀作弊；旧检索与文本接口没有退化。若 Event State 对预测无增益，禁止直接进入 Reset Policy 训练。

## Stage 2：Supervised Reset Initialization (Teacher Forcing)

**目标：** 让新生状态、旧状态预测和 Reset Policy 学会与真实事件实例对应的合理起点；不是最终事件形成机制。

1. 用 GT segment 构建 Keep / Birth 训练样本：$p_K$ 学事件内部后续运动，$p_R$ 学新事件首个 update 的出生分布；控制正负采样与事件 age，避免年龄、sensor/session 标识 shortcut。
2. GT boundary 控制事件状态更新，训练 $U_\theta$ 正确重置；随机插入同事件“伪 reset”用于抵抗小波动、对比重置收益。
3. 训练 hazard $h_\phi$ 与 Reset Policy 的初始标定，使用事件级 $\mathcal L_{weak-bnd}$（不是整个序列逐帧负样本占优的裸 BCE）。
4. 随训练逐渐降低 GT Reset 的注入比例（Scheduled Sampling），最终进行独立闭环验证。

$$
\mathcal L_2=\mathcal L_{keep/birth-pred}+\lambda_b\mathcal L_{weak-bnd}+\lambda_s\mathcal L_{sem-distill}.
$$

计算契约见 18.5：Stage 2A 先拟合条件 Keep/Birth 分布，Stage 2B 初期固定分布头、训练 prior/policy。语义项仅在可信匹配且对当前可训练参数具有梯度时参与优化；不是每个子阶段都同时优化所有项。

**冻结建议：** Encoder / 完整 LLM / Memory 冻结；初期只训 Birth Head、Reset Policy，稳定后微调 Event Update。

**验收：** 在线自驱 Reset 不产生密集抖动；重复同类动作至少具备实例分离能力；false reset same-event 与 true reset 同 age 分布可区分。GT Teacher-Forced 指标不能冒充 Closed-loop 性能。

## Stage 3：Closed-loop Predictive Event Formation（论文核心）

**目标：** 让 Reset Policy 的决策改变后续 Event State 和预测损失，形成真正的端到端事件形成学习。

- 初期 **冻结已训练 Predictor**，只优化 Reset Policy；前向采用硬 Reset，反向用 ST Gumbel-Sigmoid；TBPTT 先用 3–8 秒真实连续短序列，随后逐步延长。
- 后期有控制地解冻 Event Update Gate 和 Predictor 小部分参数，但固定 semantic reader 的被保护面，单变量消融确认增益。
- 对同一片段使用 Closed-loop 主损失 + 少量 oracle rehearsal 正则；不能将每个 update 当独立 Candidate 样本，也不能为了优化点级 AUROC 忽视最终事件 F1。

$$
\boxed{\mathcal L_3=\mathcal L_{pred}+\lambda_N\mathcal L_{count}+\lambda_B\mathcal L_{weak-bnd}+\lambda_S\mathcal L_{sem-distill}+\lambda_C\mathcal L_{state-preserve}}.
$$

**解释：** $\mathcal L_{pred}$ 通过状态更新依赖 $r_t$ 训练决策；$\mathcal L_{count}$ 限制频繁 Reset；$\mathcal L_{weak-bnd}$ 保持人类边界锚定；$\mathcal L_{sem-distill}$ 约束语义；$\mathcal L_{state-preserve}$ 保护已经验证的表示。

五项的样本集合、语义匹配、oracle 保持路径及梯度隔离消融见 18.6。Stage 3 不能根据模型预测的边界删除困难未来目标；参数冻结时仍需保留预测器对事件状态输入的梯度。

**建议的损失调度（不预先断言最佳值）：** 起初 $\lambda_B,\lambda_S$ 非零以维持语义；随后做固定权重与渐进权重两臂对照，超参数只在 fit 上确定；不能为了验证“自主学习”盲目去掉全部边界监督。

**退化诊断：** always keep、always reset、固定时长切、只靠 likelihood、只靠 GT head、预测+count、预测+count+语义；按同等 event FP/min / 帧预算比较，尤其检查 repeated same-class、slow transition、long steady、暂时噪声。

**验收：** 闭环 event F1 / FP/min / latency 相比 matched boundary-head baseline 在预注册关键指标上有收益或明确可解释的 Pareto 改善；重复动作不全被合并。若过度分割、欠分割或跨受试者 FPR 高，标记 No-Go，不自动进入下一阶段。

## Stage 4：Language-Grounded Event Alignment

**目标：** 把在线自主形成的事件表示接回 v2.5 语言空间，证明其保持语义与细节。

- 保留固定 Event Prompt；完整事件 Commit Teacher（可见整个 GT 事件），Streaming Student 只见过去；蒸馏单向 Commit→Streaming。
- 使用有 GT 实例匹配的事件文本/审核描述训练 Caption CE 和文本对比对齐；未匹配事件不能强行用 GT caption 优化。
- Evidence Projection 通过同步骨架速度、身体运动属性、位移等训练期监督，不在部署时要求姿态。

$$
\mathcal L_4=\mathcal L_{text}+\lambda_A\mathcal L_{align}+\lambda_D\mathcal L_{distill}+\lambda_E\mathcal L_{evidence}.
$$

18.7 定义目标 token CE、多正例文本对比、按属性 mask 的 Evidence 与冻结 Commit→Student 蒸馏。无可信属性标签时跳过对应项；时间戳或 MD 统计不伪装为骨架/真实位移监督。

**冻结：** 优先固定 Encoder 与 Reset Policy，训练 projector/允许的 LoRA；若要反向调整 reset，必须独立开联合微调实验，不得混入阶段主结果。

**验收：** 单事件语义/检索、时间顺序、异常动作描述、same-label repeated events 的文本覆盖；复核旧 reader 接口，不能因为纯文本能读顺序就宣称 radar tokens 能读。

## Stage 5：Hierarchical Event Memory + LLM Reasoning

**目标：** 长时保留关键语义，证明事件组织对 LLM 有实际价值。

- L0：最近事件完整 8×3584 Event Tokens；L1：多个 L0 压缩成约 4 Summary Tokens；L2：更长历史约 4 Higher-level Tokens；使用已有 1024-d Query Compressor 的 in/out 投影。
- 保存事件精修时间、confirm timestamp、confidence、retrieval key、caption 和 provisional/final 状态；检索按原 v2.5 Semantic Projection/时间/置信度组合排序。
- 完整 LLM 按需生成，不以每 0.2 秒解码自然语言作为在线硬约束。

$$
\mathcal L_5=\mathcal L_{summary}+\lambda_R\mathcal L_{retain}+\lambda_Q\mathcal L_{QA}.
$$

18.8 定义摘要/答案 token CE，以及按事件序号重建语义、时间与数量的 Retention。整体语义余弦保持仅作为辅助对照，不能单独证明重复实例与顺序保留。

**验收：** 固定总 Token Budget 下的事件覆盖、顺序准确率、细节保留、问答正确率以及 captions 的物理证据一致性。记忆模块训练不能作为 Stage 3 重置策略已经有效的证据。

## Stage 5+：可选 Joint Rate–Distortion Fine-tuning

只有 Stage 3/4/5 均通过独立门槛后，才讨论让真正的压缩代价反向训练 Reset Policy：

$$
\mathcal L_{joint}=\mathcal L_3+\alpha\mathcal L_{text/retain}+\beta\mathcal L_{MDL}.
$$

这种长链优化有极高的误差归因与算力风险；默认不属于 v2.6-MVP。不得把“可选高级阶段”写成已经实现。

# 十、在线推理状态机与算法

## 10.1 状态机

```text
IDLE ──presence──> ACTIVE
ACTIVE:
  each 0.2s: old-model forecast score + birth-model score
  q_t ← ResetPolicy(...)
  if confident keep: continue EventFormer state
  if uncertain: DEFER (pin bounded recent features; optional K=2 hypotheses)
  if confident reset: SEAL old; initialize new state; record t_reset
DEFER:
  observe at most D_max additional updates
  choose KEEP or RESET; avoid duplicate seals; reconcile if reset is backdated
SEAL:
  old event → async Boundary Refinement → Commit Teacher → Memory/Caption
  new event → provisional Active → corrected Active replay / atomic swap
```

在线 Event State 的一次硬 Reset 不代表旧事件已获得最终时间戳；时间修正、caption 可以异步完成。真实未来雷达不得参与当前预测或 Reset 决策；“Defer”只允许使用已经到达的额外观测，必须如实报告确认延迟。

## 10.2 伪代码

```python
state = init_event_state()
last_boundary = start_time
for t, F_t in streaming_updates():
    m_t = frozen_motion_target(F_t)
    if presence_is_idle(F_t):
        handle_idle_without_creating_motion_event()
        continue
    logp_keep = old_predictor.score(m_t, state, prev_motion)  # state 是 t-1
    logp_birth = birth_predictor.score(m_t, prev_context)
    q_t = reset_policy(logp_keep, logp_birth, state.age, reliability)
    decision = bounded_policy(q_t, history)  # KEEP / DEFER / RESET
    if decision == KEEP:
        state = event_former(state, F_t)
    elif decision == DEFER:
        state = update_pending_hypotheses(F_t)  # bounded memory/cost
    else:
        seal_old_provisionally(last_boundary, t)
        state = event_former(P_base, F_t)
        last_boundary = t
        enqueue_async_boundary_refine_commit_reconcile()
    prev_motion = m_t
```

训练采用两种 Update 分支和可微 ST 近似；推理在确定 Keep/Reset 时只需要选中的 Event Former 一次前向。不确定时可以保持两个状态，但需报告其 duty cycle 和 P95 时延。

# 十一、异步 Boundary Refinement 与状态一致性

## 11.1 从 Reset 时刻到真实边界

控制器给出在线 Reset/Seal 时间 $t_r$，不把它等于真实动作变化时刻 $t_b$ 或确认输出时刻 $t_c$。在 $[t_r-\delta_{pre},t_c]$ 中查找 refined boundary $\hat t_b$（上下界依当前回溯缓冲而定，避免假定重置一定晚于真边界）。

初期直接使用 $q_t$ 的局部后验轨迹/最大支持点定位；增强版利用缓存对每个候选 $b$ 从相同序列起点复现状态后，优化：

$$
\hat t_b=\arg\min_{b\in\mathcal B}
\left[\mathcal L_{old}([a,b))+\mathcal L_{new}([b,t_c])+\lambda\mathcal C(b)\right].
$$

各候选 $b$ 的评分必须基于同一总观测区间、等量可用信息、因果预测损失，不能采用“后验重构已经观察到的输入”代替预测评分。真实语义边界精度仍以 GT 标注容差检验。

## 11.2 Reconciliation

若 refined $\hat t_b\neq t_r$，在线新事件吸收的雷达区间会与最终时间线不一致。沿用 v2.5：以 $\hat t_b$ 为起点、从 $P_{base}$ 重放保存的 $F_{\hat t_b:t_{sync}}$；追赶到当前在线 update 后才 atomic swap。

Ring Buffer 按 $\delta_{pre}+D_{max}+\text{catchup margin}$ 分配；异步修正期间 pin 相关特征；完成后释放，不长期储存原始低层雷达。若缓存不足或重放超过预算，显式标记 correction_failed，保留 provisional 轨迹并阻止不一致事件写入 final memory。

# 十二、语义与压缩的明确分工

1. **预测层：** 学习能预测真实运动变化的状态；不能单独定义“值得描述的动作”。
2. **语义层：** GT 事件实例、运动属性与人工审核文本决定哪些变化在任务中应该形成独立事件；重复同类动作必须在实例级监督中出现。
3. **压缩层：** 防止每段微小噪声产生独立事件，衡量记忆 token 成本与重要运动细节损失；初期用 expected resets/sec，后期才考虑真实的压缩码率。

原则：**事件应可预测、可区分、可记忆、可描述，而不是只保证某一个 loss 最小。**

# 十三、实验设计与 Baselines

## 13.1 不可省略的主基线

| 名称 | 事件机制 | 说明 |
|---|---|---|
| B0 Window+Voting / Viterbi | 帧或窗口分类 + 后处理 | 最简单但应具有竞争力的传统路线 |
| B1 Causal TCN + Boundary Head | 逐 update 边界分类 | 直接检验是否需要重置状态学习 |
| B2 v2.5 Full | Proposal→Verify→Boundary | 原方案 matched 强基线 |
| B3 Predictive Reset (only) | 动态预测 + Reset，无语义监督 | 检验纯预测的能力和局限 |
| B4 Predictive Reset + Count | 预测 + 事件数量惩罚 | 检验过分割 |
| B5 Full v2.6-MVP | 预测 + Count + 事件级弱监督 + 语义保持 | 核心方法 |
| B6 Full+MDL（可选） | 加实际编码代价 | 只有通过信息保留实验才做 |

比较时保持数据划分、雷达 checkpoint、Event Former 初始化、实时信息约束、训练更新数、关键参数量及阈值标定协议尽可能匹配；不能以新增参数容量自动获取优势。$B3$ 可失败，其价值在于证明仅靠动力学不足以保证语义事件。

## 13.2 关键消融

- 不用 GT 重置 warm-start / 使用 warm-start；
- ST Gumbel vs Soft-state training vs K-best；
- 仅旧模型预测误差 vs old/birth likelihood ratio vs residual policy；
- 有/无 Event State，替换同容量 TCN/GRU；
- 预测 horizon 0.2/0.6/1.0 s；
- 不训练 Reset，仅 BCE 的边界头 vs Reset 参与预测梯度；
- 无语义监督 / 弱监督 / 较强实例监督；
- 0 事件成本 / expected event rate / MDL proxy；
- 纯同类重复、逐渐变化、同事件突然变化、Idle/return、missing points；
- 无 Reconciliation / 有 Reconciliation；
- 2.5 Hz vs 5 Hz、K=4/8、不同不确定性预算。

## 13.3 指标

**事件：** Boundary F1@明确秒数容差（建议同时报告 ±0.2/±0.6/±1.0 s）、Boundary MAE、event-level Precision/Recall/F1、一对一匹配、Over/Under-seg、每分钟 false final events、same-class repeat recall。原方案 F1@1/3/5 需同时注明“帧”还是“update”，不可混用。

**预测：** NLL、MSE、校准误差、variance/sharpness、按稳态/转折/噪声分组。平均 NLL 下降不等于边界改善。

**语言：** 单事件准确率、BERTScore/CIDEr（若有可靠参照）、Event Coverage、Event Order Accuracy、Duration/Temporal QA、对物理不可观测细节的幻觉率。

**在线：** P50/P95 normal update latency、DEFER/K-best 占比、reset/confirm latency、boundary refine latency、reconciliation catchup、caption lag、ring buffer 峰值、GPU RAM；实时周期 200 ms 是工程硬约束，但旧目标 P95 <70/<140 ms 仅作初始规划值，需在目标 GPU 实测。

**跨域：** Leave-subject/environment-out；分受试者报告误报与 Recall，专门报告异常高 FPR。各类输出必须区分 Oracle、TRAIN internal-dev 和真正 held-out。

### 低误报预算的公平性

此前 v2.5 工作有“8 FP/min”的物理 Proposal 校准口径；v2.6 的正式输出是 Final Event，因此不能把“候选误报数”直接与“最终错误事件数”混为一谈。比较时须分别记录 **proposal FP/min（仅旧方法）**、**final event FP/min（双方共有）**，以共同 final-event budget 为主评估，另报告候选计算量/更新延迟。

# 十四、失败模式、可辨识性与安全回退

| 风险 | 形成原因 | 检查与回退 |
|---|---|---|
| Always Keep | 过强的状态容量、Reset 成本过高 | GT 实例弱监督；报告完整漏检；若仍失败返回 v2.5 |
| Always Reset | 预测头追逐短时噪声 | 同事件伪候选、count cost、噪声增强、最短持续时间软约束 |
| 同类重复被合并 | 动力学新颖度很低 | 独立 GT 实例、重复动作专项损失和 recall |
| 快慢走被过度切分 | 运动预测收益≠事件语义 | 事件语义监督；语义一致性对照 |
| birth model 总占优 | 初始化分布尺度/方差不公平 | 负对数似然标定、same-age 与 equal-input 对照 |
| 漏检缓慢转换 | 旧状态过快适应、一步预测过短 | 0.6/1.0 s horizon；保留较慢预测参考，不伪造优势 |
| 误将丢帧/低 SNR 当 Reset | 噪声使 NLL 高 | presence/reliability gate、mask、可靠度校准 |
| ST 梯度不稳定 | 近似有偏、过早离散 | temperature 调度、分支消融、K-best 备选 |
| 模型只记用户/设备 | 硬件/场景捷径 | leave-subject/device/environment-out |
| Reader 仍不识别 Radar Tokens | 语义接口未对齐 | 单事件 text↔radar probe 先过门；不进入长时 QA |
| 训练指标好但在线差 | teacher-forcing / 未来泄漏 | 全闭环重放；预测先于观测的单元测试 |
| 内存/延迟爆炸 | 不确定时双路径过多 | K上限、timeout、FIFO queue、强制降级单状态并显式标注 |

特别说明：如果“只靠预测的边界机制”无法恢复人类语义实例边界，这可能是任务本身信息不足导致的**不可辨识性**，不能仅通过堆模型容量或反复调阈值掩盖。应将有效 claim 收紧为 *predictive-state regularized, semantically supervised online event formation*。

# 十六、预注册 Go/No-Go 门槛（建议流程，不伪造数值）

| 关卡 | 问题 | 必须展示的对照/证据 | 失败时动作 |
|---|---|---|---|
| G0 数据 | 连续 GT/帧对齐可靠？ | 标签审计、原始记录、时间轴单测 | 修数据，不训练 |
| G1 预测 | Event State 真有额外预测价值？ | 与相同历史 TCN/GRU 的 matched NLL/MSE | 不启动 Reset Policy |
| G2 重置 | 初始 policy 能找到实例边界？ | closed-loop event F1、重复事件、false reset | 修监督/识别，非直接堆模型 |
| G3 核心 | Reset 通过预测梯度改善事件形成？ | 切断预测→Reset 梯度的 matched 消融 | 否定核心机制 claim |
| G4 在线 | 达成硬更新周期且延迟可控？ | P95 latency、max defer、Buffer峰值 | 降级单状态/小 K |
| G5 语言 | 事件语义对齐与顺序可信？ | Radar-to-text probe、event order、caption audit | 不宣称完成长时理解 |
| G6 记忆 | 层级压缩保住信息？ | 固定 tokens/min 的 QA/coverage | 保留 L0，暂停 L1/L2 |

**关键的因果消融：** 保持网络结构、数据和边界弱监督完全一致，唯一改变是否允许 $\mathcal L_{pred}$ 的梯度通过硬 Reset 选择路径流回 Reset Policy。如果去掉该梯度后事件 F1 没有下降，说明当前证据**不支持**“预测驱动自主事件形成是有效机制”的主要 claim。

# 十七、推荐落地方案与论文组织

## 17.1 MVP（应最先实现）

**只做**：Frozen Radar Encoder → Event Former → Event-conditioned Predictor → Keep/Birth likelihood + Reset Policy → ST Closed-loop Event Update → count+weak GT instance supervision → event detection evaluation。

**暂不做**：完全可学习 MDL、LLM 指导每次 Reset、大型多状态 Beam Search、端到端训练完整 7B、每 update 全 LLM 生成、跨所有数据集统一训练。

**成功标准不是单看分类准确率**，而是在相同的雷达输入、标签、受试者划分、final event FP/min 和在线延迟预算下，优于边界分类基线/v2.5，且切断预测梯度会使性能显著或稳定下降。

## 17.2 论文 Method 组织

1. **Problem Formulation**：雷达流、隐式事件状态与可选 Reset，在线延迟约束。
2. **Predictive Radar Representation**：RD/Point 编码与未来 motion latent 预测。
3. **Predictive Event State and Adaptive Reset**：Old/Birth probability、hazard、可微事件状态演化。
4. **Semantically Anchored Event Formation**：事件实例弱监督、复杂度惩罚、闭环训练。
5. **Causal Boundary Finalization**：有界延迟、异步回溯边界、状态重建。
6. **Hierarchical Memory and Language Grounding**：Event Tokens → Memory → LLM。

## 17.3 可检验的论文主张

建议将论文核心 Claim 限定为：

> We study semantically constrained predictive event formation for continuous mmWave human sensing, where event reset decisions affect subsequent motion forecasting and are learned jointly with event-state evolution, enabling causal event timelines and language-grounded long-term memory.

中文：研究语义约束下的预测式事件形成，让重置决策通过改变后续运动预测来接受学习，并与持续事件状态更新联合建模，最终支持在线事件时间线及语言化长期记忆。

**最终判断：** v2.6 不应被理解为在 v2.5 的 Verify 后又加一个预测头；它将预测、状态更新和 Reset 统一为主要学习过程。作为研究计划它具有清晰的验证路径，但是否具有方法优势、是否能摆脱事件分割监督、是否能在目标硬件 5 Hz 运行，都仍是未被实验回答的问题。

# 十八、六阶段损失计算契约

**性质：** 本章规定 v2.6 拟采用的默认计算定义，并标记可选辅助臂；不表示代码已经实现或实验已经通过。第六、八、九章使用本章的有效集合与归一化口径，避免同名 loss 存在多种尺度。各阶段独立优化，不将六个阶段的损失一次性相加训练整个系统。

## 18.1 数据、符号与有效监督

| 符号 | 定义 |
|---|---|
| $s,t,h$ | 真实 recording、update 索引、预测 horizon |
| $F_{s,t},E_{s,t}$ | Radar Tokens 与更新后的事件状态；$E$ 隐藏维度 $d_E$ 配置化 |
| $m^*_{s,t}\in\mathbb R^D$ | 固定目标分支提取的运动 latent，$D$ 为实际目标维度 |
| $a_t,a_t^{reset}$ | 事件生存时间（秒）、Reset logit，二者不可混用 |
| $\Delta_{s,t},\chi_{s,t}$ | update 的合法覆盖秒数、是否允许 Reset 决策的 mask |
| $\mathcal V_{s,h}$ | 当前输入与未来目标合法、同一录制且中间没有观测断点的位置 |
| $I_{s,j},\mathcal O_s$ | 第 $j$ 个 GT 实例边界的容差窗口、可信标注的非边界位置 |
| $\mathcal M_s$ | 预测事件与 GT 实例的顺序、一对一时间匹配集合 |
| $\operatorname{sg}$ | 停止梯度；教师目标与未来运动目标使用此算子 |

目标分支包括 Radar Encoder、pooling、目标投影和归一化统计。第一版全部冻结；使用 EMA 时明确单独的目标参数与更新规则。仅对持续被优化的共享投影输出 detach，不能阻止目标跨优化步漂移。输入侧运动投影可以单独训练。

所有平均先在本 recording 的合法位置/事件上计算，再对具有对应监督的 recording 平均。文本先按单条有效目标 token 平均，Evidence 先按属性有效数平均。训练按窗口执行时记录采样权重和重复次数，维持此口径；不能让长 recording 或长 caption 自动获得更大权重。

事件 sidecar 至少提供 `recording_id, instance_id, start, end, boundary_source, boundary_valid`；文本与属性另有各自的有效 mask。连续同类别的两个事件使用不同 instance_id。未知片段不作为无边界负例，录制起点的外部初始化不计作语义 Reset。

每个 update 保存 `[start,end)` 和 `available_at`：Reset 的边界候选用 start，但读取完整 $F_t$ 的决策不能早于 available_at。缺失观测与“确认无人”分开；没有可信 presence 信息时不根据静止或低 SNR 直接标无人。

设计默认为 0.2 s/update；当前 PARrad 验证配置约为 0.18 s/update、$d_E=896$。h=1/3/5 在两种配置中的秒数不同，运行元数据必须保存实际值。无可靠骨架的 PARrad 训练不启用 Pose loss；MD 统计只能称雷达统计代理。

## 18.2 共用 Gaussian NLL 与未来目标归一化

在 $F_t$ 已经到达且形成 $E_t$ 后，预测器输出未来目标的均值与对数方差：

$$
(\mu_{s,t,h},v_{s,t,h})=D_\psi(E_{s,t},m_{s,\le t},h),\qquad v=\log\sigma^2.
$$

采用预注册上下界的有界参数化，例如 $v=v_{min}+(v_{max}-v_{min})\sigma(v^{raw})$，范围只在 fit 上确定。完整联合对角高斯 NLL 为：

$$
\ell_{s,t,h}=\frac12\sum_{d=1}^{D}\left[
\log(2\pi)+v_{s,t,h,d}
+(\operatorname{sg}(m^*_{s,t+h,d})-\mu_{s,t,h,d})^2e^{-v_{s,t,h,d}}
\right].
$$

训练用每维平均，再按有效时间步、horizon 与 recording 归一。令 $H_s$ 为存在有效未来目标的 horizon 集合：

$$
\boxed{\mathcal L_{pred}=
\frac1{|\mathcal S_{pred}|}\sum_{s\in\mathcal S_{pred}}
\frac{\sum_{h\in H_s}\alpha_h
\left[\frac1{|\mathcal V_{s,h}|}\sum_{t\in\mathcal V_{s,h}}\frac{\ell_{s,t,h}}D\right]}
{\sum_{h\in H_s}\alpha_h}.}
$$

$\alpha_h>0$；先 h=1，随后独立扩展 h=3/5。合法项不跨 recording、缺失断点或明确无人区间；不合法项跳过。目标的未来数据只进入 loss，不进入当前 predictor/policy 输入。

联合 NLL、每维平均 NLL、同 mask 的 MSE 和预测方差分别报告。NLL 可以为负；必须检查方差膨胀、sharpness、稳态/转折/噪声分组。相关 latent 的对角高斯只是工作模型，不因此宣称正确概率后验。

## 18.3 Stage 0：审计与可选物理预训练

默认复用已有前端并执行零步审计，不新增训练目标。有同步骨架且需要预训练时，设 $M_{s,t,j}$ 为有效关节 mask：

$$
\mathcal L_{MPJPE}=\operatorname{Avg}_{s}
\frac{\sum_{t,j}M_{s,t,j}\|\hat P_{s,t,j}-P_{s,t,j}\|_2}
{\sum_{t,j}M_{s,t,j}}.
$$

相邻两帧均有效、无断点且时间差为正的位置构成 $A_s$：

$$
\hat V_{s,t,j}=\frac{\hat P_{s,t,j}-\hat P_{s,t-1,j}}{\tau_{s,t}-\tau_{s,t-1}},\qquad
V_{s,t,j}=\frac{P_{s,t,j}-P_{s,t-1,j}}{\tau_{s,t}-\tau_{s,t-1}},
$$

$$
\mathcal L_{velocity}=\operatorname{Avg}_s\frac1{|A_s|}
\sum_{(t,j)\in A_s}\frac13\|\hat V_{s,t,j}-V_{s,t,j}\|_1,
\qquad \boxed{\mathcal L_0=\mathcal L_{MPJPE}+\lambda_v\mathcal L_{velocity}.}
$$

位置与速度单位、坐标参考系写入配置。训练 Encoder 与临时 Pose Head，导出移除 Pose Head。现有 `models/pose.py` 的 velocity_loss 是未除时间差的位置差分误差；改用本式时必须重新标定 $\lambda_v$，不与旧尺度混报。

## 18.4 Stage 1：预测预训练与表示保持

**Stage 1A：** 冻结 Encoder、目标分支、EventFormer 和旧 Semantic Reader，只训练 Dynamics Head 与可选输入侧投影：

$$\boxed{\mathcal L_{1A}=\mathcal L_{pred}.}$$

按可信实例边界控制 oracle reset；独立报告事件内部、跨边界与全合法流预测。仅稳态结果不能冒充连续预测收益。

**Stage 1B：** A 通过后轻量解冻 Event Update Gate/Cross-Attention/允许的 LoRA。用冻结旧快照 $U_{old},P_{old}$，在相同可见输入、初态、Reset 序列和时间上下文上计算：

$$
\mathcal L_{state-preserve}=\operatorname{Avg}_s\frac1{|V_s^{pres}|}
\sum_{t\in V_s^{pres}}
\|P_{old}(E_{s,t}^{new})-\operatorname{sg}(P_{old}(E_{s,t}^{old}))\|_2^2,
$$

$$\boxed{\mathcal L_{1B}=\mathcal L_{pred}+\lambda_{pres}\mathcal L_{state-preserve}.}$$

该项保护表示更新与旧读出空间，不强制不同事件划分的状态相同；单位向量的平方 L2 等于 $2(1-\cos)$，不重复添加同义项。Stage 1A 完全冻结表示时，该项没有新增训练作用。

Motion Attribute loss 暂列可选臂：有可信连续目标时按属性有效 mask 计算 SmoothL1；离散属性使用 CE/BCE。骨架派生量只作训练监督，无可靠标注时跳过。

## 18.5 Stage 2：Keep/Birth 拟合与事件边界初始化

### 18.5.1 Stage 2A 条件分布拟合

读取当前 $F_t$ 前，由过去准备 $p_K(m_t^*\mid E_{t-1},m_{\le t-1})$ 与 $p_R(m_t^*\mid H_{t-1})$；到达后用同一目标评分：$\ell_t^K=-\log p_K(m_t^*)$、$\ell_t^R=-\log p_R(m_t^*)$。

$K_s$ 是可信 GT 事件内部的后续 update；$R_s$ 是新 GT 实例的第一个对齐明确且有历史上下文的 update。容差窗口并不意味着窗口内每个位置都是 Birth；不明确起点先屏蔽或审校。

$$
\mathcal L_K=\operatorname{Avg}_{s:|K_s|>0}\frac1{|K_s|}\sum_{t\in K_s}\frac{\ell_t^K}D,
\qquad
\mathcal L_R=\operatorname{Avg}_{s:|R_s|>0}\frac1{|R_s|}\sum_{t\in R_s}\frac{\ell_t^R}D,
$$

$$\boxed{\mathcal L_{keep/birth-pred}=\mathcal L_K+\lambda_R^{birth}\mathcal L_R.}$$

两类样本分别平均，记录合法数量，避免普通时间步淹没少量出生位置。初期 Keep 可从 Stage 1 固定，先拟合 Birth；空集合对应项不优化。伪 Reset 来自同事件合法位置，其真实边界标签仍为负，只作受控抗扰动辅助臂。

### 18.5.2 Stage 2B Policy 与弱边界损失

先固定分布头，拟合 prior/policy 并标定证据尺度：

$$
a_t^{reset}=\frac{\operatorname{logit}(\pi_t)+\gamma(\ell_t^K-\ell_t^R)}{T_q},
\qquad q_t=\sigma(a_t^{reset}).
$$

原始似然比为 $\gamma=1$；使用额外证据缩放时仅在 fit 标定并保存 artifact。训练平均 NLL 与 Policy 使用的联合 NLL 不混用；若采用每维平均证据，重定义缩放参数。方差范围和信息可见性两臂一致。

对本 recording 的合法非空 GT 容差窗口，定义：

$$
\mathcal L_{cover}^{(s)}=-\frac1{J_s}\sum_{j=1}^{J_s}
\log\left(1-\prod_{t\in I_{s,j}}(1-q_{s,t})\right),\qquad
\mathcal L_{dup}^{(s)}=\frac1{J_s}\sum_j\left(\sum_{t\in I_{s,j}}q_{s,t}-1\right)^2,
$$

$$
\mathcal L_{off}^{(s)}=\frac1{|\mathcal O_s|}\sum_{t\in\mathcal O_s}q_{s,t},\qquad
\boxed{\mathcal L_{weak-bnd}=c_{cov}\operatorname{Avg}_s\mathcal L_{cover}^{(s)}
+c_{dup}\operatorname{Avg}_s\mathcal L_{dup}^{(s)}
+c_{off}\operatorname{Avg}_s\mathcal L_{off}^{(s)}.}
$$

各平均仅覆盖有对应有效集合的 recording。标注完整但没有边界的片段仍计算 off；未知片段不计算 off。重叠窗口按时间中点切分归属、保留各实例各自窗口；若网格上不足以形成两组不同的合法位置，则屏蔽这组无法分辨的监督并记录。不能将两条真实边界合并后只要求一次 Reset。

**实例语义项：** 令 $\mathcal M_s$ 为可信一对一匹配，$z_j^{teach}$ 来自冻结完整 GT 事件 Commit Teacher：

$$
\mathcal L_{sem-distill}=\operatorname{Avg}_{s:|\mathcal M_s|>0}
\frac1{|\mathcal M_s|}\sum_{(i,j)\in\mathcal M_s}
\left[1-\cos(P_{student}(E_i^{stream}),\operatorname{sg}(z_j^{teach}))\right],
$$

$$\boxed{\mathcal L_2=\mathcal L_{keep/birth-pred}
+\lambda_b\mathcal L_{weak-bnd}+\lambda_s\mathcal L_{sem-distill}.}$$

2A 主训条件分布，2B 初期主训 policy，再 scheduled sampling 验证自主闭环。Teacher-forced 且表示全部冻结时，语义项可能没有 policy 梯度，应仅作监测，不当作有效正则；进入可微自主路径或轻量解冻后才参与相关参数优化。

**可选替代，不纳入默认总式：** exact-one 区间项 $P_j^1=\sum_{t\in I_j}q_t\prod_{u\ne t}(1-q_u)$，$\mathcal L_{one}=-\operatorname{Avg}_j\log P_j^1$，可以替代 cover+dup 作单变量对照；非边界 BCE 可以替代 off 作另一独立对照。固定轨迹 Bernoulli 代理不等于状态依赖闭环序列的精确似然，不将这几种同目的项全部叠加。

## 18.6 Stage 3：闭环预测后果、实例语义与梯度路径

### 18.6.1 默认总目标与有效样本

$$
\boxed{\mathcal L_3=\mathcal L_{pred}^{closed}
+\lambda_N\mathcal L_{count}+\lambda_B\mathcal L_{weak-bnd}
+\lambda_S\mathcal L_{sem-distill}+\lambda_C\mathcal L_{state-preserve}^{oracle}.}
$$

$\mathcal L_{pred}^{closed}$ 使用 18.2，在模型自主硬选择后形成的 $E_t$ 上计算。目标有效性只由真实数据可用性决定，不按预测的事件边界删除跨边界目标。$\mathcal L_{count}$ 使用 8.4 的有效秒数；阈值/DEFER 后的 final events/sec 另报。

语义匹配按时间、顺序与预注册的重叠/边界容差判定，优先最大化合法一对一匹配数，再最小化时间偏差；不因为类别相同就匹配。匹配表作为无梯度的监督分配。未匹配事件不强配文本，仍计入 FP/FN。完整事件教师只作目标，早期前缀不被迫具有尚不可观测的完整语义；默认在完成事件状态计算蒸馏，前缀辅助臂使用同前缀教师。

硬匹配不可微，$\mathcal L_{sem-distill}$ 主要监督匹配事件的表示，并可能经 ST 状态路径影响 Policy；它不保证对所有漏检、多切与合并错误提供可微定位梯度。直接作用于 $q$ 的边界与数量项仍然必要。

保持项在同 GT Reset 序列、同可见前缀的 oracle rehearsal 路径计算，保护轻量解冻后的表示。可另加 oracle 预测/语义正则，但冻结所有相关参数时这些项可能是常数，不应宣称它们训练了 Reset。

### 18.6.2 真实梯度与干净消融

用第七章的 ST 变量构造 $E_t=(1-r_t^{ST})E_t^K+r_t^{ST}E_t^R$；经当前状态选择的一项局部代理梯度为：

$$
\left.\frac{\partial\mathcal L_{pred}}{\partial a_t^{reset}}\right|_{state}
\approx
\left\langle\frac{\partial\mathcal L_{pred}}{\partial E_t},E_t^R-E_t^K\right\rangle
\frac{\partial\widetilde r_t}{\partial a_t^{reset}}.
$$

后续状态递推在 TBPTT 块内继续传播该影响。Predictor/Uθ 参数可 `requires_grad_(False)`，但对状态输入的前向不得整体放入 `no_grad()` 或 `inference_mode()`；只在 TBPTT 块边界 detach，不在每次 update detach $E_t$。

核心消融保留所有结构、数据、边界/数量/语义监督，只屏蔽 $\mathcal L_{pred}$ 对 Policy 参数的梯度贡献。分损失计算梯度或构造配对计算图，保留其他损失对 Policy 的梯度及其他模块的既定优化策略。不能直接把整个共享 $r$ detach 后声称只切断预测梯度，因为这也可能切断语义损失的状态路径。

### 18.6.3 可选实例辅助，默认不要求复杂 Soft Matching

同类重复的第一项监督是独立 instance_id 和真实边界。若默认目标仍大量合并/多切，可增加独立 pair 辅助臂：

$$
S_{uv}=\prod_{k=u+1}^{v}(1-q_k),\qquad y_{uv}=\mathbb1[instance(u)=instance(v)],
$$

$$
\mathcal L_{pair}=-\operatorname{Avg}_{(u,v)}
\left[y_{uv}\log S_{uv}+(1-y_{uv})\log(1-S_{uv})\right].
$$

对同 recording 的可靠位置按同/不同实例与时间跨度分层采样；同类别不同实例仍 $y=0$，未知、不确定边界附近或中间跨无效观测区间不采样。该代理鼓励同实例无 Reset、不同实例至少一次 Reset，不保证精确事件匹配或恰好一次，不能代替最终事件级评估。默认不加含义未定的 `1-EventF1` 或复杂软匹配损失。

## 18.7 Stage 4：目标文本、语义对齐、证据与单向蒸馏

冻结 Encoder、目标分支与 Reset Policy；初期不通过语言训练修改事件切分。Teacher 保存独立冻结快照，新 projector/LoRA 不同步修改教师或旧保护面。

**Caption CE：** 对可信匹配事件 $i$ 的有效目标位置 $A_i$：

$$
\mathcal L_{text}=\operatorname{Avg}_{s}\operatorname{Avg}_{i\in\mathcal C_s}
\left[-\frac1{|A_i|}\sum_{k\in A_i}\log p(w_{i,k}\mid w_{i,<k},E_i)\right].
$$

严格使用 next-token logits；Prompt、Radar prefix 与 padding 不作目标，EOS 是有效目标。自由描述须有审核文本；类别模板只支持模板语义。

**多正例对比：** 归一化事件/文本向量为 $z_i^E,z_j^T$，$P_i$ 为可信语义等价的正例索引：

$$
\mathcal L_{E\to T}=-\frac1B\sum_i
\log\frac{\sum_{j\in P_i}\exp((z_i^E)^\top z_j^T/\tau_c)}
{\sum_j\exp((z_i^E)^\top z_j^T/\tau_c)},\qquad
\mathcal L_{align}=\frac12(\mathcal L_{E\to T}+\mathcal L_{T\to E}).
$$

反向用转置正例关系。batch 必须有有效正例和语义区分；全等价文本的零损失不能视为对齐成功。细粒度属性不同的同类别描述不机械视为等价，不将同类重复实例强推为语义负例。batch 采样按 recording 平衡，报告正例构造来源。

**Evidence：** 每个属性 $a$ 在有效标签上平均：

$$
\mathcal L_{evidence}=\sum_{a\in A_{valid}}\omega_a
\operatorname{Avg}_{s}\operatorname{Avg}_{i:mask_{i,a}=1}
\ell_a(\hat x_{i,a},x_{i,a}).
$$

连续属性用固定 fit 尺度的 SmoothL1；互斥离散属性用 CE，多标签属性用 BCE。连续 SmoothL1 明确为 $\rho_\beta(e)=e^2/(2\beta)$ 当 $|e|<\beta$，否则 $|e|-\beta/2$，多维属性按有效坐标平均，$\beta$ 存入配置。无标签属性不参与平均与优化；MD 统计代理不解释成真实身体位移。

对于离散属性 logits $l$、真值类别 $c$，$\ell_{CE}(l,c)=-l_c+\log\sum_b e^{l_b}$；对多标签属性的单个 logit $l$ 与二元标签 $y$，$\ell_{BCE}(l,y)=\operatorname{softplus}(l)-yl$，只在有效标签上平均。标签类别仅用于该属性的训练监督，不要求在线事件形成依赖固定动作类别表。

**Commit→Stream：** $\mathcal L_{distill}$ 使用 18.5 的余弦实例蒸馏；教师参数固定、目标单向停止梯度。旧代码中 Stream/Commit 两侧共同优化的一致性不是本单向目标。

$$\boxed{\mathcal L_4=\mathcal L_{text}+\lambda_A\mathcal L_{align}
+\lambda_D\mathcal L_{distill}+\lambda_E\mathcal L_{evidence}.}$$

## 18.8 Stage 5：摘要、实例保留与 Temporal QA

冻结上游事件形成与教师。先训练 Compressor/保留读出，通过后再独立解冻语言适配参数；冻结 LLM 的前向仍保留对 Memory Tokens 的梯度。

**摘要与 QA：** 对每个历史 $s$，压缩记忆为 $M_s$，摘要目标 $Y_s$、问题 $Q_{s,j}$、审核答案 $A_{s,j}$：

$$
\mathcal L_{summary}=\operatorname{Avg}_s
\left[-\operatorname{Avg}_k\log p(y_{s,k}\mid y_{s,<k},M_s)\right],
$$

$$
\mathcal L_{QA}=\operatorname{Avg}_s\operatorname{Avg}_j
\left[-\operatorname{Avg}_k\log p(a_{s,j,k}\mid a_{s,j,<k},M_s,Q_{s,j})\right].
$$

token 平均仅覆盖有效目标；QA 不把问题和 Prompt 当标签。文本来自核查事件时间线，不直接使用未经验证 LLM 的输出作真值。

**Retention 默认计算候选：** 新增按序号查询的辅助读出 $D_{ret}(M_s,k)$，输出第 $k$ 个 GT 实例的语义向量 $\hat z_{s,k}$ 与相对时间 $\hat u_{s,k}$；另由 Count Head 从 $M_s$ 预测非负 $\hat N_s$。$k$ 是查询序号，不输入 GT 动作、时间或真实事件总数。

对 $N_s>0$ 的可信历史：

$$
\mathcal L_{retain}=\operatorname{Avg}_s\left[
\frac1{N_s}\sum_{k=1}^{N_s}
\left(1-\cos(\hat z_{s,k},\operatorname{sg}(z_{s,k}^{teach}))
+\beta_t\operatorname{SmoothL1}(\hat u_{s,k},u_{s,k})\right)
+\beta_n\operatorname{SmoothL1}(\log(1+\hat N_s),\log(1+N_s))\right].
$$

$u$ 是相对当前历史范围归一化的 start/end，时间误差按两个坐标平均；同类重复有独立序号与时间目标。$N_s=0$ 时只计算合法数量目标，不计算空事件平均。严格核查实例数量未知的历史不训练 Count/实例目标。

该 Probe 是待实现的训练辅助模块，不是现有功能。现有整体余弦保持 $1-\cos(P(M),P(source))$ 可作独立辅助对照，但不能替代实例/数量/时间检验。若向 Probe 提供历史范围等元数据，固定该信息并分开报告 memory-only/带元数据结果，避免把元数据直接供给误认为 token 保存能力。

$$\boxed{\mathcal L_5=\mathcal L_{summary}+\lambda_R\mathcal L_{retain}+\lambda_Q\mathcal L_{QA}.}$$

Temporal QA 分别覆盖 before/after、同类重复次数、持续时间及事件覆盖；L1/L2 在固定 token budget 下分别报告。Stage 5 默认不反传 Reset，真实 MDL/码率反馈保留为 Stage 5+。

## 18.9 数值稳定、日志与默认项

1. Gaussian NLL、log 概率与窗口累积使用 FP32，先筛除无效目标再计算；mask 乘 NaN 不能消除 NaN。
2. cover 使用 $\log P_0=\sum\operatorname{logsigmoid}(-a_t^{reset})$，通过稳定 log1mexp/expm1 求 $-\log(1-e^{\log P_0})$；exact-one 可用 $\log P_1=\sum\operatorname{logsigmoid}(-a_t^{reset})+\operatorname{logsumexp}(a_t^{reset})$。空窗口跳过，数值保护与概率饱和次数写入日志。
3. 每项记录未加权/加权 loss、有效 recording/event/token/attribute 数量、对当前可训练参数的梯度范数；Stage 3 分别记录 pred/bnd/count/sem 对 Policy 的梯度贡献。
4. 无有效集合时跳过项并记录原因；整批没有任何有效优化信号时不执行 optimizer step。teacher、目标分支与旧保护面保存 SHA/冻结状态。
5. 所有 $\lambda,c,\alpha,\omega,\beta$ 非负，有效 horizon 权重与启用的平滑尺度为正。只在 fit 预注册有限扫描；不因原始 loss 数值接近就宣称梯度平衡，不默认要求 Stage 3 降低边界权重。

| 阶段 | 默认目标 | 可选、单独验收 |
|---|---|---|
| Stage 0 | 冻结审计；必要时 MPJPE+velocity | 新前端物理预训练 |
| Stage 1A/1B | pred；解冻时加同路径 preserve | Motion Attribute、多 horizon |
| Stage 2 | Keep/Birth NLL、cover/dup/off、有效实例语义蒸馏 | exact-one、非边界 BCE、额外 state consistency |
| Stage 3 | closed pred、count/sec、weak-bnd、matched sem、oracle preserve | pair surrogate、复杂 soft matching、多假设、联合解冻 |
| Stage 4 | 目标 token CE、多正例 align、masked Evidence、单向蒸馏 | 语言联合调整 Reset |
| Stage 5 | summary CE、实例/时间/数量 retain、Temporal QA CE | 整体余弦辅助、真实编码代价反馈 |

本章定义为实施提供可检查的计算约束；各阶段仍以第十六章 Go/No-Go 为准，公式补全不意味着数据标签已齐备或新机制已经有效。

## 18.10 可训练模块与梯度验收表

| 子阶段 | 初期可训练模块 | 关键梯度路径与冻结边界 |
|---|---|---|
| Stage 0 审计 / 可选预训练 | 默认无；必要时 Encoder、Pose Head | 姿态/速度监督→Pose→Encoder；无骨架时不启用 |

| Stage 1B | 上述参数与有限 Event Update Gate/Cross-Attention/LoRA | pred/preserve→Uθ；目标分支与旧教师固定 |
| Stage 2A | Birth Head；Keep Head 是否解冻作为独立配置 | GT 条件 NLL→对应分布参数；状态先由 GT Reset 控制 |
| Stage 2B | prior/policy；后期受控解冻 Event Update | bnd→q→policy；初期固定 Keep/Birth，不以常数语义项冒充梯度 |
| Stage 3 初期 | Reset Policy/prior | future pred→E→ST Reset→policy；冻结预测参数但保留状态输入梯度 |
