## 两个额外发现

模型磁盘上的`generation_config.json`默认含`repetition_penalty=1.1`，原实验只指定greedy，没有覆盖该值。因此原来确实带有重复token惩罚。它不是重复动作计数规则，但可能影响生成中重复短语的保留。置为1.0后，当前新提示的完整正确数提高，同时循环输出和截断也增多：不能只报告69例成功而忽略18例截断，也不能直接把1.0视为已经可用的最终方案。

原生`input_ids`与`inputs_embeds`路径在7例预检中、默认惩罚下有4例token不同；显式1.0后7例全部一致。这与重复惩罚依赖可见token历史的行为一致。本轮正式对照统一使用原嵌入输入路径；原提示、原设置的109例输出逐token复现旧结果，排除了无意换输入路径造成的改善。

自由输出的严格分数也会低估动作内容。例如第一例新提示自由输出把七个动作及最后的ongoing全部保留下来，只用了普通逗号和`and`，没有使用固定的`, then`，按原指标仍判不可解析。补充的连接词宽容核对只允许词表动作和少数连接词，拒绝额外文字、否定及未知短语：新提示自由输出在109例中有63例完整状态一致，合成41例中14例。此为事后探索性诊断，不替换预注册指标，不用来改判G0。

## 本轮实测的新文本提示

以下提示针对Text Oracle中的有序文本实例列表，不能照搬其中“逐词复制”的要求给只有雷达潜在表示的输入。

```text
Transcribe the ordered evidence entries into one sentence. This is an exact transcription task, not a summary.
Rules:
1. Read the entries from first to last. Keep their order exactly.
2. Each entry is one separate action instance. Include every entry exactly once. Do not skip, merge, deduplicate, or reorder entries. Keep both adjacent repeats and alternating repeats.
3. Copy the action phrase in each entry verbatim. Do not add or infer any action.
4. Copy ' (ongoing)' exactly for entries carrying that marker. Do not add it to any other entry or remove it.
5. For a nonempty list, output 'The person ' followed by all entries joined with ', then ', and end with a period.
6. Output 'No annotated action has been observed yet.' only when the evidence list is empty.
Before answering, silently check that the number of output actions equals the number of evidence entries, and that every phrase and ongoing marker remains at its original position.
Return only the final sentence, without explanations.
```

雷达描述提示应继承的原则是：按发生先后报告有证据支持的动作实例；保留每次重复；不把多次实例概括成一个类别；不补充未观察动作；准确标注截止时仍在持续的动作；输出前检查遗漏和顺序。雷达输入没有文本列表，不能向它提供GT的实例总数、真实顺序或真实类别集来强制正确。

## 对实验结论的更新

本轮证实提示词及解码配置是重要因素；此前判断应严格限定为“旧提示和旧解码组合未通过”，不能推断模型的一般能力不足。当前新提示仍有遗漏、错序及循环终止问题，尚未满足原定逐例全部正确的诊断条件。

下一步应先将文本读出中的顺序、完整性和终止行为稳定下来，固定新的提示/解码协议，再重跑G0雷达接口。不能把Text Oracle变好直接当成雷达对齐成功，也不能绕过G0开始G2。新的雷达提示需要单独评价，旧提示训练的Projector也不能自动视为适配新协议。
