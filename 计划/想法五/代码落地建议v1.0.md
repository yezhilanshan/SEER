# 无显式动作分段方案：代码落地建议 v1.0

日期：2026-10-18  
状态：供用户审阅的设计建议；尚未编写产品代码、启动训练或修改旧方案。  
依据：同目录《方案书v1.0.md》、当前本地源码、项目实验报告及服务器只读检查。本文不把原方案的“待定”项转为已经确认的研究设计，也不声称已经复现 LatentStream 原论文实现。

## 1. 建议采用的路线

在现有 `continuous_mmwave` 包下新增独立的 `latent_memory` 子包。复用 HARrad 冻结连续特征、局部 RadarTokenAdapter、LLM 基础调用及证据核验工具；新写按时间维护的三尺度记忆、分组 Bootstrap、多轮证据检索与 LMT 演化、连续描述数据与评价入口。

旧 v25/v26/v261、HARrad EventFormer/边界头、Stage4 EventMemory 与 QA 入口继续使用原配置和原输出。新链路不经过旧 controller，不向旧包的 `__init__` 注册默认新行为。

选择比较：

| 方式 | 优点 | 主要问题 | 建议 |
| --- | --- | --- | --- |
| 独立子包，组合已有基础模块 | 复用上游，修改范围清晰，新旧可独立运行 | 需要补齐新记忆和 LLM 接口 | 推荐 |
| 在 EventFormer/EventMemory 中增加分支 | 表面上新增文件少 | 原接口以事件为单位，分支容易继续依赖边界或 Reset | 不推荐 |
| 另建整套独立工程 | 隔离彻底 | 重复数据、前端、LLM 和核验代码，容易产生版本差异 | 暂无必要 |

## 2. 已核实的项目基础

- `harrad/streaming.py::FrozenRDStream.forward_chunk` 输出每帧 `cells[4,64]`、全局特征 64 维及连续 GRU hidden 128 维。CNN cells 不依赖动作边界重置。
- `harrad/event_data.py::prepare_features` 已导出整条录制的 cells；但同文件的 EventDataset 按官方实例裁剪，不能直接当作新方案的数据集。
- `harrad/event_semantic.py::RadarTokenAdapter` 只处理相邻两帧及其有效 mask，输出 4 个 256 维 Token；本身不要求动作边界，可独立复用。EventSemanticModel 则含事件状态、成熟度和实例监督，不整体迁移。
- `parrad_memory.py::EventMemory.add` 要求 8 个事件 Token、事件起止与确认时间，并包含事件合并/晋升；它不是新方案的连续时间记忆。
- `models/memory.py::QueryCompressor` 的张量运算可供后续参考，但包含 event_position、事件组输入和 max_events 约定；旧压缩器权重没有在 HARrad 连续时间单元上验证，不直接视为可用模型。
- `models/event_former.py::Qwen2Adapter` 提供 embedding、逐层注意力和完整 CausalLM 调用；构造时自动加入 LoRA，默认取前四层的语义路径也不同于新方案所需的完整 LLM 隐藏状态路径。
- `stages/parrad_stage4.py` 的 chat prompt 和生成函数可组合复用；`chat_supervision` 有 512 Token 长度限制，`generate_from_memory` 默认最多生成 96 Token，完整录制描述不能盲目沿用这些限制。
- 项目报告记录：旧 EventFormer 实例监督模型在无 Oracle Reset 的连续诊断中 Macro-F1 为 12.89%；这不证明新方案不可行，但说明不能把旧 Event State 直接当作可靠的长时记忆。该数字来自已有报告，本轮没有重跑其预测。

## 3. 新链路与复用边界

```text
原始 RD ──复用 FrozenRDStream──┐
                            ├─ 连续 cells + 真实时间戳
现有完整录制 cells 缓存 ──────┘
                                      │
                            按时间写入 Short/Mid/Long
                                      │
                   当前有界记忆 → 局部适配与 LLM Projector
                                      │
              固定指令 + 三组 Initial LMT + 分组可见记忆
                                      │
                        冻结完整 LLM Bootstrap
                                      │
              按组检索 → 注入证据 → 冻结 LLM 更新 LMT
                                      │
                    使用更新的 LMT 再检索，重复 R 轮
                                      │
                         Evolved LMT → 文本生成
```

首轮建议优先使用 `cells.npy`，避免重新导出雷达或改变 CNN。连续 GRU hidden 可保留为后续单独输入消融，不将按实例重置的 `oracle_hidden.npy` 输入新链路。

相邻两帧用于张量计算/Token 适配属于固定步长计算单元，不是动作分段。PairBuffer 在录制起点建立；查询、动作变化、官方起止标签均不清空它。奇数尾帧保留或显式带 mask 处理，实际证据截止时间必须记录，不能借下一帧凑满。

建议优先尝试加载旧 checkpoint 中 `tokens.*` 对应的 RadarTokenAdapter 参数，作为冻结局部适配器；必须验证键、形状和本地前向一致性。它只是初始化候选，不能把旧实例语义成绩视为新系统成绩。另加新 Projector 映射到 LLM hidden size，后续是否解冻局部适配器单列实验。

## 4. 必须新增的核心模块

### 4.1 连续时间三尺度记忆

新的 MemoryItem 保存特征、有效 mask、观测起止时间和源帧索引，不保存动作类别、事件 ID、置信度、确认时间或 caption 作为检索输入。

- 写入、层间转移及压缩只由已到达的时间/容量驱动，不调用边界头或变化点检测。
- Short 保留近期细节，Mid/Long 保存更早的多尺度历史；三组检索范围分别是 S、S∪M、S∪M∪L。
- 首轮建议以时间驱动的确定性池化作为压缩基线，保留原时间区间与源索引；具体池化粒度/容量仍需确认。该策略可能损失重复动作及顺序，必须通过后续消融衡量。
- Jenks、学习型压缩器作为以后可替换策略，不自动加入首轮。
- 保留低维冻结特征，在读取时应用可训练 Projector；不长期缓存已经 detach 的可训练投影结果，避免梯度中断和参数更新后的陈旧向量。
- 外部记忆的数量有显式上限。Bootstrap 读取的是当时保留下来的有界三尺度记忆，不将整个原始历史一次塞进 LLM，也不省略规定的 Bootstrap 而用一次 top-k 代替。
- 即使压缩后保留时间元数据，也不宣称能够无损保存所有动作或无限历史。

### 4.2 冻结 LLM 后端与 Bootstrap

新增后端包装，优先组合项目现有 LLM 基础调用；不通过修改旧 Qwen2Adapter 的默认行为完成新功能。

- 从模型配置获取 hidden size，不在新模块里写死 896。
- 新后端不自动打开旧 LoRA；HME 所用 LLM 参数冻结。首轮建议生成侧也冻结，以便聚焦验证记忆机制；生成侧 LoRA 是以后单独确认的选项。
- 固定指令、投影记忆和三组可学习 Initial LMT 共同进入完整 LLM，提取约定层的 LMT 隐藏状态；不在 Bootstrap 生成文字，也不用时间锚点代替此步骤。
- 必须显式实现分组可见性，并验证底层注意力实际应用了 mask；普通二维 padding mask 不足以表达它。
- 限制需覆盖间接信息路径：不能让 Short LMT 经共享的、已混入 Long 信息的中间 Token 或其他 LMT 读到 Long。可以先采用逐组独立前向验证，再优化为等价分块 mask；优化前后做数值对照。
- 冻结参数不等于对训练前向使用 `no_grad`。Bootstrap/HME/生成损失仍需向 Initial LMT、Projector 等新参数反传。
- 真实时间与 LLM 的序列位置分别记录；时间表示是可替换接口，具体编码方式仍待确认，不能把 RoPE 序号直接当作雷达真实时间。

### 4.3 逐轮检索与演化

每组当前 LMT 在其合法候选池内计算相关性，选取证据后保留时间信息，再用冻结 LLM 更新该组隐藏状态。下一轮必须重新计算分数和选择，不能仅对第一次选出的证据反复更新。

检索采用确定性并列排序，记录每轮候选、分数、选中源索引及前后 LMT 变化。检索排序用于选择证据，注入时仍保留可识别的时间顺序。短历史导致某一层为空、证据少于检索预算等情况必须正常工作。

硬 top-k 索引不可微，不把检索选择称为端到端可微模块。首轮可以通过选中证据内容与 LMT 更新链训练；如果引入可学习相似度投影或分数加权，需要单独验证其梯度路径，再确定具体选择方法。

每次周期查询建议从同一组可学习 Initial LMT 重新 Bootstrap；外部记忆继续积累。跨查询继承上一轮 LMT 尚未确认，首轮不默认开启。

## 5. 数据与训练建议

### 5.1 必须区分输入和监督

新运行时只接收连续特征、有效 mask、时间戳和固定指令。官方动作区间可以离线用于训练目标及评价，但不能进入记忆写入、LMT 初始化、查询时间选择、检索或状态重置。

沿用 subject1–6 训练、subject7 验证、subject8–9 暂不读取信号的现有开发划分，避免同时改变模型和划分。新 Dataset 不调用 EventDataset、旧 joint_data 的 latest_start 前缀裁剪，也不先按动作拼接片段。

固定周期查询点独立于动作标签生成；训练可以对既定查询点抽样，但前向必须重建同一录制的真实过去记忆，不能把截断窗口伪装成完整历史。

### 5.2 连续描述监督的缺口

已检查的 HARrad 管线提供 12 类动作及区间，尚未提供覆盖整段的连续自然语言描述。因此第一阶段建议构造“已标注行为的顺序描述”监督，并明确它是受限的弱文本监督：

- 只根据截止时刻以前可见的标注生成参考；保留相邻同类的独立实例，不做重复折叠。
- 重复次数优先指官方实例次数，不能把实例数自动解释成一次实例内部手势/运动周期的次数。
- 不以截止时刻之后的实例、终点或时长构造当前参考。
- 查询点落在动作中间时，必须单列进行中动作的标签表达和评价规则；不把官方已知的未来结束时刻暴露给模型。
- 未标注区间仍连续输入模型，不自动标为空闲、静止或无动作。完整描述可能包含未标注但实际发生的行为，不能仅凭缺少 GT 就算成错误；对此单列未知区间及人工抽查结果。
- 仅靠区间类别无法监督动作幅度、速度、细节变化或精确重复次数。首轮可验证顺序及已标注行为保留；“细节描述”需额外人工描述/可信参考后再评价。

建议先验证 Qwen 对正确文字行为证据的顺序、重复及描述任务是否能生成合理答案，作为解码诊断；该文字对照不进入真实雷达推理，也不把旧 14 类 PARrad QA LoRA 默认为 12 类 HARrad 描述模型。

### 5.3 首轮训练范围

建议冻结 CNN、选用的局部适配器和 LLM，仅训练新 Projector、三组 Initial LMT，以及经确认确有梯度路径的新对齐参数。先以回答 Token 的标准 teacher-forced CE 为训练候选，不自动加入 PMO、熵奖励、计数损失或序列辅助损失。具体目标仍需用户确认。

R=0 对应 Bootstrap 后直接生成；R>0 对应多轮检索演化后生成。既报告同一权重切换 R 的推理消融，也做各自训练、相同样本和优化预算的主对照，两种结果分开解释。推理耗时及 LLM 调用次数分别报告，不能将多轮调用的收益全部归因为重新检索。

## 7. 推荐实施顺序与验收

1. **协议与缓存接入**：核验输入哈希和完整帧覆盖；实现不依赖标签的固定周期查询及录制状态。标注加载只属于监督/评价侧。
2. **三尺度记忆**：先用小张量验证时间驱动写入、压缩、容量、时间戳、空层与快照恢复，检查未标注帧没有被过滤。
3. **真实 LLM Bootstrap**：验证完整 LLM 隐藏状态回读、各组 mask、冻结权重和输入梯度；先在真实 Qwen 上确认兼容，再扩展训练。
4. **多轮 HME**：保存可回放的逐轮检索轨迹；使用受控输入验证证据变化可引起重新检索。真实样本每轮选中相同证据也可能合法，不强制制造变化。
5. **描述监督与小规模训练**：先做文字证据诊断和少量训练录制的拟合检查，再在固定面板比较 R=0/R>0；不自动启动长训练或追加预算。
6. **完整连续回放与独立核验**：从录制起点顺序输入，周期查询不清空记忆，输出文本、源索引、检索分数、时间和显存；重载权重独立重放，检查原方案兼容性。

关键检查包括：不规则分块等价；未来帧扰动不影响更早输出；不允许超截止压缩单元；查询不触发 buffer/记忆重置；Short 不读取 Long 的直接或间接证据；梯度确实到达新参数；冻结权重不变；padding 不写入记忆；相邻同类与交替重复均保留；长答案截断单列；同配置恢复后输出可复现。

主评价建议报告已标注动作序列的编辑距离/完整序列正确率、官方实例重复次数误差、早期/中期/近期信息保留、遗漏，以及生成文本可解析率和截断率。对动作细节、未知区间真实行为与自由表述，单列人工核查，不能直接用旧 QA 字符串判分器替代。所有比较在相同查询点、标注覆盖和生成预算下进行。

必要对照为 Bootstrap-only 与 Evolved；建议额外包含固定证据重复更新（区分再检索价值）、同样更新轮数的证据重排、无雷达/错配证据，以及有界原始记忆直接读出。三尺度、时间编码与压缩策略的扩展消融在主链路有效后开展。

## 8. 实现前应明确的设计选择

以下是待确认的配置/实验选择，不是已承诺的默认值：

- 首轮是否采用 HARrad cells、冻结旧局部适配器和本地 Qwen2.5-0.5B；Projector 的具体结构。
- 固定指令文字、输出语言、进行中动作与未标注区间的描述/评价口径。
- 查询周期、三层容量及压缩粒度、时间编码、LMT 数量、每轮检索预算与演化轮数。
- 第一阶段是否接受按官方区间构造的弱文本监督；是否补充人工连续描述。
- 训练步数、种子、模型选择规则、输出长度及显存/延迟预算。

推荐先确认上述第一版实验配置，再编写并验证独立旁路。当前建议不改变《方案书v1.0.md》的研究边界，也不声称冻结 LLM 加随机 Projector/LMT 即可直接获得有效描述。
