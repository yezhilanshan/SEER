# v2.5 gate 行为迁移与新任务分阶段提案草案

日期：2026-10-07。状态：待审阅；未修改训练代码、模型或服务器配置，未启动新优化。

目的：先让不输入 age/maturity 的新 gate 接住旧 Stage2 的检索行为，再验证物理属性监督和负 alpha 是否提供新能力。原 encoder、EventFormer 主干、P、Memory compressor 与 QA 保持冻结。数据分区沿用 dataset-v2；录制留出、subject12 和官方 test 继续封存。

## 1. 核实后的事实与修正

### 输出范围、函数表示和权重迁移分开讨论

在相同 previous、proposal、alpha 下，`previous + alpha*(proposal-previous)` 与 `torch.lerp` 数学等价；不同算子和精度下不保证逐位一致。sigmoid 输出范围包含于 tanh 输出范围，因此新更新式能表达旧的一次状态更新。但这不能证明删去 maturity 的固定宽度 MLP 能表示旧 gate 的全部函数或轨迹。

设旧 MLP 输出为 z。复制旧权重、删去第一层 maturity 列后，把 sigmoid 换为 tanh，会从 sigmoid(z) 变成 tanh(z)，两者不相等。正确的输出坐标转换是 `g(z)=atanh(sigmoid(z))`，数学上也等于 `0.5*softplus(z+log(2))`；随后 tanh(g(z)) 才等于 sigmoid(z)。这一额外非线性不是原新 gate 中已有的线性权重转换。如果采用它，必须单独注册架构，不能把它包装成原结构的无变化热启动。

删掉第一层 maturity 列、保持原 bias，等价于旧 MLP 固定 m=0 的前激活；固定 m=c 时需把 `W_m*c` 加到第一层 bias。这个结论先于 sigmoid/tanh 转换，不能据此声称新 tanh 输出等价。Commit 教师使用 m=1，Stream 教师使用随 prefix 增长的原 maturity 规则，不能只在 Commit 上量损失。

### 现有监督覆盖不能仅凭张量相同判错

`GateBatches` 的 Stream 接续上一 chunk 的状态，覆盖 `[run.start,end)`；TBPTT detach 切断梯度，不重置可见历史。Commit 输入也是 `[run.start,end)`。因此两路用相同前缀物理 target，在目前“可见事件前缀平均属性”的定义下成立；把 Stream target 改成最后一个 chunk 的均值反而会改变任务。

需要补的是显式覆盖元数据与自动测试：各路记录 visible_start/end、target_start/end、有效帧和缺样 mask；对非恒定属性、长 run 接续、不同起点、前缀与局部窗口构造可区分样例。若以后把 Stream 属性定义为当前局部运动而 Commit 为事件整体属性，必须另改 target 定义与 schema，不能静默切换。

### 指标实际状态

训练入口 `fixed_query_retrieval` 目前只返回 mAP/R@1；独立读回脚本已计算并保存 R@5 与 margin。当前 R@5 定义为 top5 至少一个相关事件的查询命中率，margin 是“最佳正事件分数减最佳负事件分数”；不能把它当成全部正负对的排序保持。下一轮应把这些口径纳入正式报告/schema。

自动事件的 GT 时间窗匹配检索命中、覆盖和误事件率尚未实现；边界 F1 已实现，动作 F1 尚需单独实现。A 阶段的固定 GT run 检索是迁移控制实验，不能代替最终自动事件库评估。

用户评估中的个别 sensor 数值与已读回结果对调：-7.45pp 的 Stream mAP 对应 subject03/14xx；-0.10pp 对应 subject04/68xx。报告和后续分组以保存的 UID/metadata 为准。总体失败结论不变。

## 2. 前置四族零步诊断

这是拟议的下一轮准备，不表示已经执行。所有分支 optimizer=0、eval 模式、同一缓存/14查询/记录 UID/精度/旧 P；只读 fit 和已授权 dev，不读留出。

| 家族 | 变体 | 隔离内容 |
|---|---|---|
| A | 旧 gate 原样，Stream 原 maturity 规则、Commit m=1 | 原教师参照 |
| B | 旧 gate 分别固定 m=0、m=1 | 去掉显式 maturity 的两种条件对照 |
| C | C-raw：拷贝兼容权重、固定条件折入 bias 后直接 tanh；C-exact：仅诊断使用上述精确输出变换 | 区分拷贝权重与输出坐标转换；不预设 C-raw 约等于 B |
| D | seed42 原全新初始化 tanh gate | 已有零步结果；核对来源一致后复用，不重复伪装为新证据 |

两类前向分别执行：

1. teacher-forced：相同旧 previous/proposal 下跑旧 gate m=0/1 和各 C，记录 alpha、状态差；固定参考输入使局部影响可归因。
2. free-running：各分支从原初始 token 自行生成 proposal、滚动自身状态；至少64 updates及完整长 run，并独立执行 Commit。不能一直喂旧状态然后声称递归已等价。

保存 alpha 差的中位数/p95/p99/max、逐步状态范数/teacher 范数比、归一化状态误差、两路 key cosine 尾部、查询排序和各 subject×sensor 指标。零步诊断不选择最好的 dev 分支重新定义成功标准；拟议部署路线在优化前另锁定。Delta alpha 大只能说明 maturity 敏感，不能证明需要 age 替代输入；是否能由当前可见状态/雷达证据预测旧更新行为须在 fit 检验。禁止把经过时间、更新次数或其简单变换伪装成新输入。

## 3. 迁移阶段：只训练 gate

建议 seed42 固定1000实际 AdamW 更新；250步同输入 teacher-forced 拟合，750步 free-running 表示与检索保持。所有步合并计数，不用 dev 选最佳中途 checkpoint。teacher-forced 阶段允许旧状态作为明确标记的拟合输入，free-running 阶段不得把旧状态当学生接续状态；这需要修订原计划“旧 Event State 不作新训练输入”的条款。

拟议默认先维持当前 tanh MLP 结构，继承兼容权重的初始化身份为 `v25-age-free-tanh-warmstart-v1`；C-exact 作为函数转换诊断，不默认为部署结构。如果零步结果显示该热启动不可用，停止并另锁方案，不直接切换到另一架构开始训练。

迁移期间 alpha 目标取旧教师的正区间，学生负 alpha 加显式惩罚并完整报告其比例，不把默认 tanh 改成未经标注的 sigmoid。若要采用硬限域，要另外规定可训练参数化、饱和梯度和解限后的行为，不能只临时 clamp。通过迁移不等于负 alpha 能力已学会。

训练目标包括同输入 alpha 拟合、相对状态误差、Stream/Commit 同前缀 key 保留，以及检索排序保持。损失数值系数、阶段内权重和是否采用限域，应在最终训练计划中锁定，草案不构成可执行配置。

排序分两种：事件对正确/错误查询的 margin 属于分类约束；mAP 需要同一查询下正事件/负事件的排序约束。先用 fit 标签及教师分数筛出教师原本排序正确的困难正负对，要求学生分数差不低于对应教师差；不强制保留教师误排。各路独立报告。相似度矩阵计算便宜，但生成当前学生事件 key 的前向并非零成本；负例库的来源、刷新周期和梯度范围必须锁定，避免拿固定旧负例 key 冒充当前学生完整排序。

验收沿用原同数据检索门槛：旧回归 dev 与完整 dev，各路 macro mAP/R@1 下降不超过1pp；各 subject×sensor 下降不超过3pp。同时报告逐类 AP、top5 命中、分数差、尾部 key 偏移和逐步范数。额外范数界应基于 fit 教师测量预注册，不能直接把历史峰值1364当当前安全阈值；凸组合也只对给定 previous/proposal 有局部界，不保证依赖状态的整个递归系统全局有界。

## 4. 新任务：Evidence 两级路线

第一级：迁移达标后冻结 gate/P/主干，Evidence stop-gradient 固定500步。两路覆盖契约先验收，dev masked MAE须比 fit 每 sensor 中位数常量降低至少10%，逐属性/传感器分列。这验证冻结表示的可解码性，不宣称已经把物理信息写入状态。

第二级：仅当第一级失败且标签、有效覆盖、优化确实正常，允许在单独批准的路线中增加小型 Evidence 专用残差 adapter，固定250步，原 gate/P冻结；adapter 不改变检索/QA token。若属性改善，仅说明专用表示塑形有用，不满足“共享事件状态获得新属性”。失败也不能二分证明信息不存在，仍可能是头容量或优化问题。

修改共享 Event State 的低 lr adapter 或受范数限制的属性回传属于后面的最小 joint 分支；它必须同时保留检索与历史 QA 回归，不能作为 B 失败后的隐式自动动作。

## 5. 闭环与最终评估

迁移及 Evidence 达标后，Local/Radar1000、Semantic oracle250、闭环 hard-pair1000沿用原任务骨架；需要重新批准修订后的完整训练顺序。所有依赖 frontend 的 feature/pair/probe/calibration 证书重建，不能复用旧 digest 冒充当前状态。有限校准、完整闭环、边界、Memory/QA和节拍回放均为0优化更新。

自动事件评估与固定 GT run 控制实验分列。GT 只在离线评分中使用，不触发 Confirm。最终报告按GT时间窗衡量自动检索的 top-k 命中、被覆盖GT事件比例和返回误事件比例；匹配重叠比例、容差、混合事件/重复事件的处理和分母，在最终计划中预先锁定。动作 F1 的任务单位与动作来源也需明确，不与已有边界 F1 混用。

## 6. 兼容双路与最小 joint：独立可选分支

双路只保护交付，不计作新 gate 检索通过。建议保护路线由旧路独立完成 Confirm、boundary、Commit、Memory与QA，新路先只作旁路诊断；这样已有交付行为可直接核对。两路同 watermark、同事件起止范围，但状态分别重建与验证。若选择新路驱动切分、旧路编码Memory，则新边界通过重建改变旧 token，属于跨路耦合，必须明确标记、重新验收，不能声称旧 Memory 未受影响。

若要求完全禁止新 boundary 影响旧路，旧路必须保留自身切分；此时无法同时保证任意新路切分与旧路切分完全共享。不能把这两项矛盾条件写成同一个通过标准。双路增加前向后重新测0.18s节拍p95与积压；报告新路独立检索的已测损失和最差组，不能宣称未知条件的损失上界。

最小 joint 是迁移/任务解耦路线之后的单独提案，建议最多500步，只更新已命名的共享小adapter，P仍冻结；持续保留同数据两路检索与QA门槛。负 alpha 的解限属于此处拟议的创新试验：需要独立的状态纠错/撤销目标及旧教师之外的监督，不能以“允许负值”代替“学会撤销”。该目标尚待定义，所以不在当前草案中授权执行。

P 解冻更靠后，最多另提250步，必须同时包含低 lr、P 自身 anchor、匹配预算的冻结P对照。历史QA数值不作废，仍保存为历史基线；新P对事件key和查询key的改动会使当前路径兼容性需要重新测量，不能直接引用80.47/84.34/74.75作为新路径结果。配对同数据旧模型对照继续保留。

| gate迁移＋stop-grad Evidence | 1500 | 新提案批准；gate1000通过才做Evidence500 |

| 最小joint | 额外500 | 独立目标/共享参数/损失/安全界及新缓存方案批准 |

以上都是新提案预算，不继承旧轮未用预算的自动授权。旧轮1000更新保留历史记账；新主线3750则累计4750，新主线含专用adapter则累计5000。不自动开seed43；是否复现及其上限另锁，失败训练也计入预算。

新增批准项：热启动初始化/架构身份、teacher-forced旧状态输入、迁移损失与顺序、可选adapter、负alpha创新、双路runtime、P解冻及对照。允许的 gate 家族须白名单注册并携带初始化来源和转换参数SHA；不删除或通配放宽架构守卫。checkpoint/controller/stage2/stage3 cache及所有writer统一升级并拒绝错误旧证书。

当前最小决策是先审阅零步诊断和迁移路线；后续分支没有被批准，也没有开始执行。
