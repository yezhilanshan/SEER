Interfaces fixed for integration:
- model.MVPConfig(feature_dim=128, hidden_dim=128, num_classes=12, frame_period_s=1/15, state_tau_s=2., current_max=3.) dataclass.
- model.ActionHead(config); model.EvidenceNet(config, use_state:bool); evidence.forward(h, previous_h, previous_state)->logits, tensors [N,H] or [H].
- model.rollout(features, action_head, evidence, config, mechanism='lif', threshold=1., tau=1., teacher_boundaries=None)-> {'events':list, 'trace':dict[str,np.ndarray]}. trace MUST keys frame, evidence, voltage, fire, state_distance, probabilities. Event fields match event_gating metrics schema. Only TRAIN may supply teacher boundaries; evaluate never does. Every feature row corresponds one original frame.
- data.load_records(settings)-> list rows with x finite np.ndarray/memmap [T,128], labels ndarray [T] -100 unknown, boundary_target ndarray [T], boundary_mask bool[T], boundaries list of internal integer frame indices, known_frames bool[T], plus original file/subject/role/frames/instances.
- data.split_fit_calibration(records)-> (fit:list, calibration:list, validation:list), one lexicographic-last train recording per subject; reject insufficient recordings, all validation separate.
- metrics.evaluate_rollout(result,record,period=1/15)-> JSON dict including boundary at .2/.5/1 seconds and event scores at IoU .3/.5, valid-region FP/min, unknown count, oversegmentation, diagnostics.

Engineering decisions: use official [start,stop), nominal native15Hz; unknown gaps preserved; gaussian width .2s positives allowed near official boundary with unknown far regions masked. Calibration grid fixed in config, select on calibration only by boundary F1 at .5s, recall then lower FP, deterministic simple ties. B1->B2 and B2->B3 reports do not assert gates pass from smoke. No LLM in this scope.
