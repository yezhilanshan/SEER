# 实验二：GT / 十份约束随机排列 / No Reset

授权：用户要求进行实验二。沿用 Stage1 冻结来源、25fit/6cal/4subject7 录制、256维固定未来目标、0.2/0.6/1.0秒、三训练seed42/43/44、每模型1000更新，不启动Reset Policy。

每条录制通过独立随机抽样生成10份不同排列。保留按更新步计的间隔多重集及重置次数；实际帧时间的最小间隔必须与GT一致；排序后的实际帧间隔与GT逐项差最多2帧。非初始随机重置时刻不得与任何GT起止点精确重合。所有约束在预测误差计算前检查，无法生成则停止并报告，不放宽。公布全部实际间隔、分布差异和拒绝抽样次数。排列来自同一受约束分布，不称为完全无条件随机。

固定原GT观测网格及雷达输入，重置时刻为当前更新的观测起点 cutoff-2。No Reset仅录制起点初始化，状态与年龄连续累积，年龄输入依原设计封顶1。该设计隔离状态重置与年龄历史，不能分离两者独立作用。

为避免批处理数值差异混入比较，GT状态与其他11组同时批处理重建，并匹配预算重训全部36个模型；原GT模型另外保留作复现参照。先检查显存、有限值与第一条录制，再完整执行。35录制12组约40GB事件缓存，独立输出目录保留旧结果和失败证据。

报告各seed/跨度/录制MSE、NLL、方差、覆盖率；10份排列的均值、标准差、范围及GT/NoReset所处分位。排列先在各seed/录制内配对，再平均；主区间为整录制配对Bootstrap，另报排列波动，不能把10份排列视为10名受试者。随机化胜率作描述，不宣称10次约束抽样提供强显著性检验。subject7单受试者限制保留。

训练结果须有保存预测独立复算、精确同目标、全排列约束检查和新实例权重重载回放。排序全部按观测结果报告，原NoGo保持。
