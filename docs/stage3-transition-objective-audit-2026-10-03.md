# 转换训练目标与评估衔接核查

状态：两次真实数据诊断均完成。初次2026-10-03 13:52:14–13:54:15，补充14:01:35–14:02:47(+0800)。只分析既有权重，Projection优化步数均为0；诊断线性分类器仅使用fit数据，未改变生产或实验checkpoint，未启动新Projection训练。

## 核查结论

评估实现未发现成绩计算错误。明确的训练目标差异是：约76%的训练权重落在age3–5，而选择成绩只看age6/7；最终Candidate权重并未做到类别各占50%；临时分类头也仍有较大的拟合优化空间。

固定Projection的配对诊断确认：仅限制分类器拟合年龄，就明显提高主评估AUROC。这支持下一步优先对齐转换任务年龄与权重，而非继续增加语义约束。尚未通过新的Projection训练证明这些差异足以解释全部无收益，也不能保证修正后会超过原模型。

## 2. 多数训练权重落在主评估之外

fit共4804行、1299个Candidates，dev共2072行。主评估范围fit1414行、dev640行。

| 年龄 | fit行数 | 最终训练权重占比 | 权重后的正类比例 |
| --- | --- | --- | --- |
| age3 | 1299 | 31.81% | 12.26% |
| age4 | 1254 | 30.41% | 16.60% |
| age5 | 837 | 14.11% | 19.65% |
| age6 | 761 | 12.78% | 22.88% |
| age7 | 653 | 10.89% | 24.85% |

age3–5共占 **76.33%**，主评估age6/7仅占 **23.67%**。较短寿命Candidate只有早期行，Candidate等总质量使这些行获得更大质量；不能只按五个年龄推断每个年龄各占20%。

`balanced_candidate_weights`先计算每年龄类别因子(限制.25–4)，再把每个Candidate的总权重归一到1。age3正类因子触及4上限，随后Candidate归一化进一步改变各年龄类别质量。最终整体加权正类只有 **17.35%**，不是50%。这不违背Candidate等总质量约束，但与独立probe的每年龄类别平衡目标不同；函数名或中间balance因子不能证明最终类别平衡。

## 4. 临时head尚未拟合充分

将临时heads的预测也按相同主范围和聚合重算，warmup为.50451，head-only最后一轮.54094，relation1最后一轮.51697，relation10最后一轮.52502。之前报告中的pooled dev诊断值与这些分组聚合值不同，不能直接比较。

在同一完整fit加权BCE上，原Projection下head-only最后一轮损失 **.60112**；只输出fit正类先验的常数分类器可以达到 **.46141**(其AUROC为.5，仅是损失/校准诊断，不是更好的检索或转换模型)。这说明当前head连该加权BCE的简单可达水平都未达到。

保持特征、标签、容量及完整fit权重不变，从已保存heads出发继续优化无ridge的BCE，可把损失降到约.39066(两个joint约.3885/.3881)。但这些无ridge诊断达到400迭代上限而未满足收敛，所以不把其dev成绩作为有效模型结果或声称已找到最优head。另一个有ridge的共享诊断head在86–88次迭代满足原规则，fit目标约.4213–.4217。

这里比较的是快照的完整fit损失；训练日志是训练中各mini-batch损失的均值，两者不是同一个统计量。诊断不能单独证明换优化器或增加epoch就必然改善开发集，但足以否定“临时头已经拟合充分”的假定。

## 6. 归一化不是目前最明确的问题

训练归一化固定在旧Projection的全部age fit统计，独立probe则按每年龄及当前Projection重新计算。虽然协议不同，本次没有发现数值爆炸：标准差floor列数0，fit标准化输入绝对值p99约3.97–4.05，最大约8.16–9.59。原Projection下从固定归一化的分年龄head到原独立probe的诊断差别约.00282，小于年龄范围变化；不能据此把全部失败归因于归一化。

## 下一步调整顺序

1. 保持当前teacher关系保留方案和原评估门槛，先让主要转换任务对齐age6/7；age3–5如果保留，应是显式权重的辅助项，避免暗中占76%质量。
2. 明确选择Candidate公平质量还是主年龄类别平衡，并输出最终质量统计。两者需要一起约束/定义，不能假设先balance再归一化就同时满足；任何变化先固定新协议，不偷偷修改旧标准。
3. Projection解冻前，先在fit范围检查head的可达损失及收敛/梯度，而非固定1epoch就认定预热充分。先做冻结Projection的同容量对照，再决定是否进入新适配小实验。
4. 不因诊断分类器.63240就宣告成功；后续Projection仍需按原独立probe及完整语义门槛验证。本次没有启动上述调整后的训练。
