# 单事件QA适配层固定预算实验

用户已批准单事件基线、独立QA适配层、平衡正反监督和一次500步固定预算训练。先训练生成接口，不训练压缩器或改变原检索路径。QA适配层为896→256→896的逐token残差MLP，带LayerNorm，末层零初始化，起点严格恒等；只把适配后的token送给冻结Full Qwen。原始L0、检索P、EventFormer、LoRA及LLM保持冻结。

只用已核验295事件TRAIN缓存：subject02/sensor14xx，set000/001拟合196事件，set002开发99事件。每个事件建立一个动作名称任务；另建立同一个问题在正、反两个实际事件上的Yes/No配对，负例在同一cohort优先选择混淆动作，选择固定seed42。不跨fit/dev取负例，负例复用不当作独立样本。

基线比较原L0、正确动作文字的诊断上限、无记忆；文字上限将动作名称放在user消息内，仅用于基线、不进入适配层训练或实际雷达输入。动作识别为14类闭集，固定候选表对所有事件相同，不泄露对应答案。QA前后保存实际greedy回答，统一规范答案评分。

500次实际AdamW更新，lr0.001、weight_decay0.01、clip1、AMP初始scale256，seed42。每次更新一个同问题正反对和一个动作识别任务，三条微批答案CE取平均；正反答案权重严格相等。训练按可用动作类别轮转抽样，以免频繁动作控制更新。100/250/500保存；以最终500步报告，不挑选开发集最佳检查点。只优化QA适配层，无须给生成分支施加原检索键损失；原P永远读取未适配token。

结束后分别报告动作识别总体/逐类/macro recall、正反各自正确率及平衡准确率、每对两个答案都正确的比例、无记忆和错记忆对照。替换成配对的相反事件会交换Yes/No参考答案，以检查证据反转；按原参考评分的错记忆性能另报，不能把换证据后的正确答案误记为失败。无记忆不用于训练。首轮工程推进目标：动作macro recall与存在性平衡准确率≥80%、配对均正确≥70%、存在性比无记忆高≥20个百分点；样本量与失败完整报告，这不是正式Go标准。

保存task来源、cache/protected compressor/前端/代码SHA，核验原token/原检索键和完整上游权重未变，独立读回三个检查点真实优化步数与推理导出。实验输出独立目录，拒绝重复worker，完整保留失败。不会因为未达标自动增加预算、解冻原LLM或启用QA LoRA；不会在本轮先扩展多事件/在线压缩。

仍是上游见过的单受试者TRAIN开发录制，开发集已在旧实验使用，不能称为新的独立测试或未见受试者泛化。
