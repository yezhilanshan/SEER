## 2. 误差增加来自什么样的修正？

令标准化当前、未来目标为x、y，真实增量d=y−x，神经预测增量a=μ−x。逐对验证了：

\[
\underbrace{\operatorname{mean}(\mu-y)^2}_{M}
=\underbrace{\operatorname{mean}d^2}_{P}
+\underbrace{\operatorname{mean}a^2}_{A}
-\underbrace{2\operatorname{mean}(a\cdot d)}_{2C}.
\]

式中乘积逐坐标计算后求均值。神经预测要优于Persistence，需要对齐收益2C超过修正能量A。

| validation宏平均 | 修正能量A | 对齐收益2C | 净增加MSE：A−2C | 增量方向余弦 | 单位置胜过Persistence比例 |
|---|---:|---:|---:|---:|---:|
| 无事件MLP | 0.050421 | 0.012780 | 0.037640 | 0.1662 | 6.77% |
| GRU | 0.048102 | 0.014207 | 0.033895 | 0.1821 | 5.35% |
| TCN | 0.049241 | 0.014674 | 0.034567 | 0.1793 | 3.92% |
| Event | 0.053546 | 0.013693 | 0.039854 | 0.1679 | 4.15% |

Event的误差可精确写成0.033655 + 0.053546 − 0.013693 = 0.073509。其他神经臂也一样：修正与真实变化有一些正向对齐，但远不足以抵消修正自身的能量。这是对已发生误差的精确解释，尚不是学习率、目标或结构的单一根因证明。

没有发现明显的常量预测塌缩：validation逐坐标预测时间标准差/目标时间标准差，先维度再录制平均，四臂约为1.026/1.019/0.994/1.022。预测保留了大部分总体变化尺度，却没有足够准确地预测细小的下一步变化。Event平均误差偏置RMS约0.0847；不能把全部误差解释为均值被压到0。

Gaussian方差也没有触及上下限附近（logvar<−5.99或>1.99的比例均0）。但存在欠覆盖：各神经臂每坐标平均标准化平方误差为1.41–1.58，1.96σ覆盖约88.99%–90.38%，Persistence为94.13%。因此没有观察到“顶着方差上限作弊”，也不能说概率预测已经校准；均值误差和方差问题应在后续受控实验分开判断。

## 3. 分层后没有出现被总体均值掩盖的优势

低/中/高变化按真实标准化增量RMS分组；fit录制等权分位数阈值为q50=0.1495168482、q90=0.2673812026，先固定阈值再分析validation。低变化是相对分组，不等同于物理静止或无人。高变化分组使用真实未来变化，属于诊断条件，不是部署时可用的输入。

## 4. 确定的评估盲区：所有代理边界都被预测mask切断

| 按录制计 | fit，18份 | validation，6份 |
|---|---:|---:|
| 内部命令边界数（双传感器重复计） | 1,768 | 468 |
| 边界落在update内部的混合update | 1,768 | 468 |
| 缓存invalid update总数 | 1,768 | 468 |
| 截断前全部合法h1对 | 57,856 | 19,169 |
| 前32步视图选中对 | 50,044 | 13,559 |
| 全部合法h1对中的cross | **0** | **0** |
| 选中对中的cross | **0** | **0** |

根因可在代码中定位：

1. `targets.py:39`要求一个update首尾属于同一命令episode，否则valid=false。
2. `targets.py:56`要求当前至未来沿途的valid全部为真。
3. `features.py:179`用同一valid生成未来配对。

这把“代理事件归属混合”与“运动观测无效”合并了。首轮输入MD是完整编码的，但边界处的latent被排除出合法预测路径，因而不能用这次任务判断模型是否善于预测跨事件转换。

**这是我首轮实现中需要纠正的mask契约。**应在新协议中区分观测有效性与事件状态归属有效性；P0只定位问题，没有修改缓存或重跑首轮指标。

也不能把cross=0只归因于“前32步”：截断前的合法h1对已经完全不跨界。near对仍存在，fit保留7,201/8,823（81.62%），validation保留1,834/2,336（78.51%）；validation的near保留率甚至高于总体70.73%。因此，“前32步把所有边界邻域都丢掉”并不符合本轮数据。

以下使用全缓存合法连续位置、原fit归一化，先录制后受试者等权。h>1仅为现有latent的只读时滞统计，未训练任何神经多horizon臂。由于沿用原valid，统计仍条件于不经过上述边界混合update，不能代表跨边界动力学。

| h1，0.18秒 | 0.982956 | 0.983335 | 0.032417 | 0.031287 |

## 7. 研究判断与下一步边界

| 原诊断假设 | P0证据后的判断 |
|---|---|
| 神经预测未达到Persistence | **确认**：全fit、实际见过位置、validation均如此 |
| 预测均值塌成常量 | **不支持**：时间标准差接近目标、优化显著改善 |
| 修正方向/幅度不合适 | **确认现象**：A明显大于2C，增量余弦仅0.17–0.18左右 |
| 只是稳态占比大，掩盖了转换处收益 | **观察到的分组不支持**；真正cross组为空，不能判断跨界收益 |
| 当前评估覆盖事件转换 | **否**：mask切断全部代理边界，需修正契约 |
| 特征短时很平滑 | **支持**；不证明mean pooling或Encoder是根因 |
| 300步已经充分收敛/只是加步数即可 | **均未证明**，不据此追加预算 |
| Event Tokens无用或完整v2.6失败 | **仍不能推出**：冻结短训读出，且Keep/Birth/闭环均未执行 |

如果之后开展P1，应先在新协议中分开“观测有效”与“代理段归属有效”，再检验零初始化的残差均值是否能保住Persistence起点；若要固定方差或扩预算，应作为可归因的独立对照，避免同时改动多项。当前没有自动开展这些修改，也没有开始Reset训练。
