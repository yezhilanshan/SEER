# P1-C：完整因果回放与多 Horizon 诊断协议

2026-10-15；本次授权范围：冻结前端回放、数据契约、无训练基线、下一轮实验准备。本次不执行优化器、不训练 Reset。P1-C 是预测诊断，不构成正式 Reset 训练的启动条件。

## 输入与冻结边界

沿用 v4/P0 锁定的 18 条训练、6 条验证录制、原始 F/motion、Stage1/Stage2/Qwen、训练集统计量和受试者划分。读取原缓存中的整段 F，不重新训练编码器。测试集不读。原先 63,603 个 h=1 选点仅用于兼容核验，新的预测索引不再用代理纯度筛选有效观测。

## 两种完整状态轨迹

- **Oracle Reset（延后到纯 Update）**：录制/观测连续段起点初始化；混合 Update 使用此前状态正常更新，不接收类别、未来命令、事件总时长。首次纯 Update 的已观察代理事件编号变化时，在该 Update 更新前 Reset。标签仅由截至本 Update 截止时刻已发生的命令起点决定。此规则兼容旧缓存跳过混合 Update 后的重新初始化；它是命令代理 Oracle，不是真实实例边界，也不是自主 Reset。
- **No Reset**：每个录制的有效连续观测段只初始化一次，之后从不根据代理标签重置。遇到缺测/时间间断显式开启新连续段，不跨不可观察间断造状态。本批若无缺测则每条录制仅一次初始化。
- 两者都保存每个有效 Update 的更新后 E、实际已观察 age、segment_start、Reset 标志。maturity=min(age×0.18/1.2,1)，不读事件终点，无 32 步截断，不执行 Commit/Memory/LLM 输出训练。
- batch=1，原 FP16 autocast 数学；存储 FP16 是原输出值的无损保存，不将 FP32 计算结果量化来伪造一致。有限性、状态范数及冻结权重 SHA 必须检查；不以裁剪或偷偷 Reset 掩盖长时漂移。

## 必须通过的核验

1. 有效观测到 E 一一对应、时间顺序与行数一致；混合 Update 全部覆盖；旧源文件、训练产物、模型权重不变。
2. Oracle 在全部旧选点与原冻结缓存逐元素完全一致。No Reset 首次 Oracle Reset 前应一致，之后允许因策略不同而不同；不能要求它复现 Oracle。
3. 对两种轨迹分别进行普通逐步 stream_update 与 CUDA Graph 的初始连续段核验，以及长尾局部逐步续算核验。后者以完整回放保存的前态为条件，不冒充整段独立逐步回放。
4. 每条录制选取首次混合 Update 之后的截断前缀，删除/移动/增加截止后命令并替换雷达后缀：此前计划与状态均须完全不变。命令文本/类别从未传入回放；No Reset 更需对任意代理时间表不变。单元测试覆盖缺测与时间间断。
5. 交付完整状态文件 native 路径、SHA、逐录制审计、可独立核验的 compact 索引和探针；不只交结论。

## 多 Horizon 主诊断

h∈{1,3,5} 对应 0.18/0.54/0.90 秒，目标是原运动特征 m[t+h]。所有 Horizon/模型用同一合法起点集合：t-1、t 到 t+5 有效且连续；加入 t-1 是为了线性趋势基线。记录相对 P1 common_start 丢弃数量。

基线：Persistence=m[t]；线性趋势=m[t]+h·(m[t]-m[t-1])，不用未来估计速度、不以验证结果调倍率/裁剪。训练前可计算这两项，MSE 在原 fit-only 标准化空间中计算。线性趋势没有已校准方差，不伪造 NLL。

后续神经头统一零初始化残差、相同训练/验证划分、每个 Horizon 相同 300 次更新×batch8、种子42、AdamW lr=.001/wd=.01/clip1，与 P1-B 对齐。为排除 Horizon 混淆，先各 Horizon 独立训练头，当前尚未执行。训练采样表在训练前固定，各臂/各 Horizon 共用 recording/start，不能按验证表现改变训练预算或选 checkpoint；保留 0/50/100/200/300，只比较 final300。

报告每录制、受试者宏平均 MSE、对 Persistence 和线性趋势的 Skill；跨界定义为(available[t],available[t+h]]内出现代理边界。额外分别报告 mixed_current/mixed_future 与其并集；“干净内部”要求三者均无，不能把所有非 deadline_cross 称为纯事件内部。每组报告样本数，空组为 N/A。

## 信息消融与历史匹配

- A：正确 E；B：同架构/参数的错配 E；C：保留相同 Event 预测头、E 置零的容量对照（由可训练偏置提供常量表征），另列原 motion-only Residual-MLP，区分输入信息与头容量；D：GRU/TCN。
- **B 的预固定 causal-age-v1 规则**：同一录制内，从已经结束的其他 Oracle 状态段中，抽取与当前 E **精确相同观测 age** 的状态；因此受试者、会话、传感器、年龄完全一致，供体截止时间严格早于当前截止时间、不允许自配、不使用类别/未来目标。按 SHA256('p1c-causal-age-v1:t:age') 在候选中取模，索引先于预测训练冻结。
- 缺少供体的起点不能偷偷补零、跨受试者或从未来抽样。A/B/C/D 都在同一 ablation_common_start 子集比较，并同时报告覆盖率/丢弃偏差。该控制保持年龄与身份条件，仍不保证内容分布完全相等：过去事件状态可能含通用或重复事件信息，因此是保守负对照，不是严格“无信息”样本。
- **No Reset 单录制中 age 单调增加，精确年龄匹配的过去供体不存在**。本批不声称实现 No Reset 的公平 B；若后续要做，需要另外获得同受试者同传感器独立录制的状态，并锁定供体池及因果可用时间。当前 No Reset 用 A/C/D 与状态漂移作诊断，B 标 N/A。
- D 不能只取最近32步却声称匹配整段 E。Oracle 的 GRU/TCN 使用同一个 segment_start 到当前的全部 F；No Reset 使用同连续观测段的全部 F。GRU 完整展开并在预算中计入计算成本；TCN 的因果感受野预先覆盖各视图最长连续段（kernel2、dilation=1/2/...，层数由最长长度确定），逐层左 padding，禁止对称 padding。层数/参数量与容量差异必须报告，可调头宽以接近参数预算但不按验证分数调。长段训练若改 TBPTT 或截断历史，必须另列为不匹配的诊断，不能沿用 D 名称。
- 正确 E 优于 GRU/TCN 仍不足以归因事件信息。需同时优于 B 和同容量 C，并报告预训练容量与 Oracle 边界额外信息的局限；单 seed300 步只作可行性诊断，不作为正式收益或 Reset 放行。
